# m2.5_mirror / m3_mirror — Weyl phonon 재조사 (독립 수행)

기존 문서 참조 없이 `source/m2.5_mirror`, `source/m3_mirror` 만으로 새로 조사했다.
사용량 제약으로 **가볍게** 돌렸다(쐐기 N=31, chirality 는 검증된 Berry flux).

## 0. 결론

**두 구조 모두 band 17-18 에 진짜 Weyl phonon 이 있다.**

| 구조 | Weyl 위치 (환산) | gap (THz) | χ | 주파수 |
|---|---|---|---|---|
| **m2.5_mirror** | (0.2076817, 0.2955478, 0.4345807) | 3.6e-15 | **+1** | 11.87886 THz = **49.13 meV** |
| **m3_mirror** A | (0.2052705, 0.2675182, 0.4418585) | 0 | **+1** | 11.98525 THz = **49.57 meV** |
| **m3_mirror** B | (0.2016153, 0.1734079, 0.2936153) | 0 | **−1** | 11.65585 THz = **48.20 meV** |

χ 는 반지름 0.002 / 0.004 에서 동일(흔들림 없음).

세 노드 모두 **완전 일반위치**다 — 거울지표(k1, k2)에서도, 편극축 nodal plane
(k3 = 0.5)에서도 떨어져 있다. 대칭 궤도는 (±k1, ±k2, ±k3) 8점이고 거울에서 χ 가
뒤집히므로 궤도당 +4개/−4개, 알짜 0이다. 따라서 BZ 전체에

- **m2.5 : 8개** (계열 1개)
- **m3 : 16개** (계열 2개)

## 1. 대칭 (두 구조 동일)

```
공간군 Pca2_1
거울지표 = k1, k2   (chirality 0 강제)
편극축   = k3       (2_1 screw)
```

`k3 = 0.5` 는 2₁ screw + 시간역전이 축퇴를 평면 전체에 강제하는 nodal plane 이다.

## 2. 전역 탐색 (phonopy, 기약 쐐기 31³)

| | 쐐기 최소 gap | 국소최소 | 거울면 | 일반위치 |
|---|---|---|---|---|
| m2.5 | 3.59e-10 | 41 | 37 | 4 (중복 제외 3) |
| m3 | 6.50e-10 | 46 | 40 | 6 (중복 제외 4) |

일반위치 후보 중 `k3 = 0.5` 위의 것들은 nodal plane 이라 제외된다. 남은 것이 0절의
표다.

## 3. `k3 = 0.5` 위의 χ 값은 의미가 없다 (읽는 법 주의)

nodal plane 위에 중심을 둔 구는 축퇴면에 관통되므로 구면 위상수가 정의되지 않는다.
실제로 값이 일관되지 않는다:

```
m2.5  (0.2290007, 0.3087282, 0.5)  -> chi = 0
m2.5  (0.0143293, 0.4304547, 0.5)  -> chi = +1   <- 정의되지 않는 값
m3    (0.2210464, 0.2831224, 0.5)  -> chi = 0
```

같은 평면 위에서 0 과 +1 이 섞여 나오는 것 자체가 "정의 안 됨"의 증거다.
**이 평면 위 숫자는 인용하지 말 것.**

## 5. 한계

- **쐐기 N=31** 이다 (parent_pristine 은 41). 간격 0.0167 이라 아주 날카로운 노드는
  놓칠 수 있다. 0절의 셋은 확실하지만 "이것뿐"이라고 단정하지 말 것.
- **chirality 는 Berry flux (Fukui-Hatsugai-Suzuki) 자체 구현**으로 구했다.
  parent_pristine 에서 Simphony 와 개별값·상대부호·합이 전부 일치함을 확인한
  구현이며(전체 부호 규약만 반대), 여기서도 반지름 두 값에서 안정적이다.
  Simphony 직접 확인은 구조마다 hr.dat 생성(~5분)+실행이 필요해 이번엔 생략했다.
  필요하면 `results/parent_pristine/SUMMARY.md` 13절 절차 그대로 하면 되고,
  **`Nk2 ≥ 800`** 을 잊지 말 것.

## 6. 검증 — 편극축=0 평면에 왜 노드가 없나 (탐색 누락 아님)

이전 구조들(pristine/m1/parent_pristine)에서는 Weyl 이 **항상 편극축=0 평면**에
있었는데 m2.5/m3 결과에는 없다는 지적이 있어 따로 검증했다. **실제로 없다.**

### (a) 그 평면만 조밀 스캔 (161×161, 간격 0.0031)

```
m2.5  전체 최소 2.86e-10 (거울선 위) | 경계에서 떨어진 최소 4.63e-03 | 거울면 밖 국소최소 0개
m3    전체 최소 6.50e-10 (거울선 위) | 경계에서 떨어진 최소 2.12e-03 | 거울면 밖 국소최소 0개
```

### (b) 양성 대조 — 같은 스캔이 parent_pristine 에서는 노드를 잡는다

```
parent_pristine  경계에서 떨어진 최소 2.32e-03
                 후보 k=(0.1469, 0.0719, 0.0000)   ← 알려진 노드, 정상 검출
```

**주의**: m3 의 평면 최소(2.12e-03)가 parent_pristine(2.32e-03)보다 오히려 낮다.
즉 gap 크기만으로는 판정할 수 없어 아래 (c)가 필요하다.

### (c) 최저 내부점들을 정밀화하면 전부 거울선으로 흘러간다

거울선에서 0.033 이상 떨어진 내부 최저 6점을 각각 평면 안에서 정밀화한 결과:

| 구조 | 정밀화 도달점 | 거울선까지 거리 |
|---|---|---|
| m2.5 | 6/6 전부 (0.5, 0.5) | 0.0000 |
| m3 | 3/6 (0.160458, 0) · 3/6 (0.5, 0.5) | 0.0000 |

**일반위치에 머무는 점이 하나도 없다.** 골짜기가 전부 거울선 nodal line 으로
배수(drain)된다 — 거울선 위는 χ=0 강제이므로 위상적으로 무의미하다.

### 결론

**편극축=0 계열 Weyl 은 m2.5·m3 에서 소멸했다.** 압축 변형이 그 계열을 거울선으로
밀어 소멸시킨다는 기존 메커니즘과 정확히 일치하며, (c)의 "골짜기가 거울선으로
빨려든다"는 것이 그 소멸 직후 지형이다. m2.5·m3 에 남은 것은 **그 계열이 아니라
완전 일반위치의 별개 계열**(0절)이다.

### 지금 확실한 것 / 아닌 것

- **확실**: 0절 세 노드는 gap ~1e-15, χ 가 반지름 0.002/0.004 에서 안정. 실재한다.
- **확실**: 편극축=0 평면에는 없다 (위 (a)(b)(c)).
- **불확실**: **완전성**. 쐐기 N=31(간격 0.0167)이라 더 날카로운 일반위치 노드가
  추가로 있을 수 있다. "이 셋뿐"은 아직 못 박을 수 없다.
- **불확실**: 이 두 구조에 대한 **Simphony 독립 확인**은 아직 안 했다
  (parent_pristine 에서는 일치를 확인했다).

## 7. N=61 재검 — m2.5·m3 는 변화 없음

5절의 "완전성 불확실(N=31)" 항목에 대해 **N=61**(간격 0.0083)로 다시 돌렸다.

```
m2.5  일반위치 후보: (0.2076817, 0.2955478, 0.4345807) 하나 (나머지는 k3=0.5 평면 중복)
m3    일반위치 후보: (0.2016153, 0.1734079, 0.2936153), (0.2052705, 0.2675182, 0.4418585)
                     (나머지는 k3=0.5 평면 중복)
```

**두 구조 모두 N=31 결과와 동일하다.** 0절의 표는 그대로 유효하다.

단, 같은 N=31→61 재검에서 `parent_m1_old` 는 노드가 **하나 늘었다**
(`results/parent_m1_old/SUMMARY.md` 7절). 즉 N=61 도 수렴의 증명은 아니다 —
m2.5·m3 에서 안 늘었다는 사실이 "더 없다"를 보장하지는 않는다.
