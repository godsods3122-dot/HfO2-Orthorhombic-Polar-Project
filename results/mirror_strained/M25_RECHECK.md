# m2.5 (−2.5% biaxial) Weyl 위치 재검증 — 2026-09

레포 안에 **서로 모순되는 두 기록**이 있어서 직접 다시 계산했다.

| 문서 | 주장 | 판정 |
|---|---|---|

| `CLAUDE.md` §2.3 | m2.5 에 Weyl **없음** | **틀렸다 (정정함)** |
| `results/weyl_trend/SUMMARY.md` | 일반위치 최소 gap 6.67e-3, 닫히지 않음 | **틀렸다 (정정함)** |

## 1. 노드는 실재한다

`source/m2.5_mirror` 만 가지고 phonopy 4.4.0 으로 독립 계산
(`symmetrize_force_constants_by_space_group` + level 3, Gonze NAC).

| | 값 |
|---|---|
| 위치 (환산) | **(0.2076817, 0.2955478, 0.4345807)** |
| band 17–18 gap | **3.92e-08 THz** |
| 주파수 | **11.878864 THz = 49.13 meV** |
| chirality (Berry flux, FHS) | **+1** — r = 0.002 / 0.004 / 0.008 1/Å 에서 전부 +1.0000 |

3.92e-08 은 이 설정의 **수치 바닥**이다. 대칭이 축퇴를 정확히 강제하는
`k3 = 0.5` nodal plane 위에서 같은 방법으로 재도 1.8e-07 이 나온다.
즉 gap 값만으로는 "정확히 0"과 구별되지 않고, **판정 근거는 χ 가 세 반지름에서
모두 정수 +1 로 안정하다는 것**이다.

격자 미세화(gradient 미사용, half 를 1e-2 에서 1e-5 까지 4배씩 축소)를 6단계
돌려도 점이 전혀 움직이지 않는다 — 이미 국소최소 바닥이다.

## 2. 완전 일반위치다

```
공간군 Pca2_1   거울지표 k1, k2   편극축 k3
```

- `k1 = 0.2077` — 0, 0.5 어느 쪽도 아님
- `k2 = 0.2955` — 0, 0.5 어느 쪽도 아님
- `k3 = 0.4346` — nodal plane `k3 = 0.5` 에서 **0.0654 떨어져 있음**

대칭 궤도는 8점이고 전부 같은 gap 바닥에 있다 (3.9e-08 ~ 1.7e-07, 수치 잡음 범위).

```
(±0.2076817, ±0.2955478, ±0.4345807)
```

거울 2개가 χ 를 뒤집으므로 +1 넷 / −1 넷, 알짜 전하 0.

## 3. 왜 "없음"으로 잘못 결론냈나

**type-II 콘이라 노드 주변 골이 얕아서, 대칭면으로 배수되는 골짜기들이
격자 gap 순위에서 진짜 노드를 앞선다.**

기약 쐐기 N=61 (226,981점) 일반위치 후보를 gap 순으로 세우고 **전부** 미세화한 결과:

| 순위 | 격자 후보 | 격자 gap | 도달점 | 최종 gap | 판정 |
|---|---|---|---|---|---|
| 1 | (0.1667, 0.0083, 0.1083) | 1.62e-3 | (0.1621, **0.0000**, 0.1058) | 1.9e-07 | 거울면 k2=0, χ=0 |
| 2 | (0.2083, 0.3083, 0.4917) | 2.13e-3 | (0.2118, 0.3044, **0.5000**) | 1.8e-07 | nodal plane, χ=0 |
| 3 | (0.2083, 0.3000, 0.4917) | 2.32e-3 | (0.2118, 0.3044, **0.5000**) | 1.8e-07 | nodal plane, χ=0 |
| 4 | (0.2083, 0.3167, 0.4917) | 2.42e-3 | (0.2116, 0.3056, **0.5000**) | 1.8e-07 | nodal plane, χ=0 |
| 5 | (0.2167, 0.3000, 0.4917) | 2.49e-3 | (0.2118, 0.3044, **0.5000**) | 1.8e-07 | nodal plane, χ=0 |

진짜 노드가 **7위**다. 상위 4개만 미세화하면 100% 놓친다.
이전 조사가 정확히 그렇게 했다.

`weyl_trend` 가 최소 gap 이라고 적은 `(0.1818, 0.0563, 0.1410)` 의 6.67e-3 은
재현되지만(6.6656e-03), 그 골짜기는 미세화하면 거울면 `k2 = 0` 으로 배수된다.
노드가 아니라 거울선 nodal line 의 사면이다.

### 교훈

**후보는 gap 순위로 자르지 말고 전부 미세화한 뒤, 도달점이 대칭면인지로 걸러낼 것.**
대칭이 강제하는 축퇴(nodal plane, 거울선)는 격자 위에서 항상 더 깊어 보인다.

## 4. 대칭 강제 평면 재확인 (무작위 200점씩)

| 평면 | gap 최소 | 중앙값 |
|---|---|---|
| **`k3 = 0.5` (편극축 nodal plane)** | **4.03e-09** | **5.92e-08** |
| `k3 = 0.0` | 3.27e-04 | 2.89e-01 |
| `k1 = 0.0` | 3.93e-02 | 2.63e-01 |
| `k1 = 0.5` | 4.66e-06 | 5.15e-02 |
| `k2 = 0.0` | 1.99e-03 | 1.42e-01 |
| `k2 = 0.5` | 3.07e-04 | 1.83e-01 |

`k3 = 0.5` 만 평면 전체가 축퇴다 (2₁ screw + 시간역전). 나머지 거울면은 그 안의
nodal **line** 에서만 축퇴한다.

**`k3 = 0` 평면(=다른 구조들에서 Weyl 이 살던 평면)에 노드가 없다는 것은 여전히 맞다**
— 최소 gap 3.27e-04. 즉 "polar=0 계열은 m2.5 에서 소멸했다" 는 결론과
`weyl_trend` 의 strain 민감도 행렬 분석은 영향받지 않는다.
틀렸던 것은 **"m2.5 전체에 Weyl 이 없다"** 는 문장뿐이다.

## 5. 남은 것

- **Simphony 독립 확인**: 여기 χ 는 자체 구현 Berry flux (FHS) 다.
  `parent_pristine` 에서 Simphony 와 개별값·상대부호·합이 일치함을 확인한 구현이지만
  (전체 부호 규약만 반대), m2.5 에 대해 Simphony 로 직접 돌린 적은 아직 없다.
  절차는 `results/parent_pristine/SUMMARY.md` §13, **`Nk2 ≥ 800`** 필수.
- **완전성**: 이 궤도 하나뿐이라고 단정할 수 없다. N=61 에서 gap 2.8e-3 이하
  일반위치 후보를 전부 훑은 결과이고, 더 얕은 노드가 더 있을 수 있다.
  m3 에는 궤도가 2개(총 16점)다.
