# Weyl phonon 을 고대칭 경로 위로 — glide 만 부분적으로 깨는 경로 (P2₁)

`scripts/order_break.py` 로 검증. 구조는 `source/pristine_mirror` (Pca2₁, 축 규약
거울 = k1,k3 / 편극축 = k2). 대상은 band 17–18.

전제: **shear·전단으로 Pca2₁ 을 직접 깨는 방법은 배제**한다. 아래는 수직 변형도
전단도 쓰지 않고, 조성·미세구조 규칙배열만으로 가는 길이다.

---

## 0. 결론 먼저

Pca2₁ 에서 **chirality = 0 을 강제하는 것은 glide 거울 두 개뿐**이다. 편극축의 2₁
나사축은 `k_polar = 0.5` nodal plane 하나만 강제하고 고대칭 경로에는 아무 제약도 걸지
않는다. 그러므로

```
mm2 (Pca2₁)  →  2 (P2₁)      glide 2개 제거, 2₁ 유지
```

가 **강유전성·편극축·편극 방향을 그대로 둔 채** 표준 경로를 여는 최소 대칭 축소다.
그리고 이 축소는 **셀을 키우지 않는다** (index-2 translationengleiche 부분군, 12원자
그대로 → BZ folding 없음).

실제로 해보면, 기존에 쫓던 (0.0975, 0, 0.1610) Weyl 을 옮길 필요조차 없다.
**Γ–Z 위 k3 = 0.2185 에 이미 gap=0 인 점이 있고**, Pca2₁ 에서는 거울면 nodal line
이라 χ=0 이라 무의미했을 뿐이다. glide 를 깨면 그 자리가 **χ = −1 인 진짜 Weyl 로
바뀐다.** 옮기는 게 아니라, 이미 경로 위에 있는 것을 위상적으로 켜는 것이다.

| | Pca2₁ | P2₁ (규칙배열) |
|---|---|---|
| Γ–Z 위 k3=0.2185 | gap→0, **χ = 0** (거울면 nodal line) | gap→0, **χ = −1** (고립 Weyl) |
| 같은 nodal line 의 k2=0.03 지점 | gap ~1e-4 (선으로 이어짐) | **5.4e-3 (열림)** |
| 같은 line 의 k2=0.10 지점 | gap ~6e-5 | **1.0e-2 (열림)** |
| 모드 주파수 | 10.334 THz | 10.334 THz (344.7 cm⁻¹, 42.74 meV) |

즉 nodal **line** 이 gap 이 열리면서 **점 하나로 수축**하고, 그 점이 정확히 Γ–Z 위에
남는다.

## 1. 왜 2₁ 은 놔둬도 되는가 (대칭 회계)

spglib 이 준 4개 조작 (`weyl_scan.py --mode sym`):

```
op0  E
op1  R=diag(-1, 1,-1)  t=(0,½,0)   2₁ screw ∥ 편극축(k2)
op2  R=diag( 1, 1,-1)  t=(0,½,½)   glide ⊥ c   → 거울지표 k3
op3  R=diag(-1, 1, 1)  t=(0,0,½)   glide ⊥ a   → 거울지표 k1
```

- χ=0 을 강제하는 것은 **op2, op3** (거울은 chirality 를 뒤집는데 불변면 위의 점은
  자기 자신으로 가므로 χ = −χ = 0).
- **op1 은 χ 를 보존**한다. op1 이 혼자 강제하는 것은 `k2 = ½` 의 nodal plane
  (2₁ + 시간역전) 뿐이다.
- `k2 = 0` 평면에서는 **C2·T 가 각 k 를 고정**한다 (op1: k→(−k1,k2,−k3), T: k→−k,
  합성 → (k1,−k2,k3)). (C2T)² = +1 이므로 이 평면 안에서 해밀토니안이 국소적으로
  실수가 되고, gap 닫힘이 2조건/2변수 → **평면 안에서 점 노드가 generic**하다.
  기존 Weyl 이 하필 k2 = 0 에 정확히 앉아 있던 것은 우연이 아니라 이 보호 때문이다.

**직접 확인 (질량 규칙배열로 glide 만 깬 계산):**

| 경로 구간 | Pca2₁ | P2₁ | 판정 |
|---|---|---|---|
| Y–T (k2 = ½ 평면) | 2.27e-9 | **2.25e-9** | 2₁ 이 지키므로 **살아남음** |
| Z–U (k3 = ½ 평면) | 9.29e-10 | **3.35e-2** | glide 가 지키던 것이라 **사라짐** |
| X–U (k3 = ½ 평면) | 9.29e-10 | **6.57e-2** | 사라짐 |
| Γ–Z | ~1e-8 (선) | 점 하나만 | 아래 3절 |

`k3 = ½` 전면 축퇴는 이 저장소가 아직 문서화하지 않았던 **두 번째** nodal plane
이다(기존 SUMMARY 는 편극축 `k_polar = ½` 만 기록). 세 glide/screw 의 교환자가 모두
`e^{-i2πk3}` 를 내므로 `k3 = ½` 에서만 반교환 → 축퇴. glide 를 깨면 없어진다.

## 2. P2₁ 을 주는 규칙배열은 "C2 짝" 하나뿐이다

`--mode enum`. 12원자 셀의 세 4a 궤도 각각에서 2+2 로 쪼개는 6가지 중, **op1(C2)이
서로 맞바꾸는 짝**을 고른 2가지만 P2₁ 이고 나머지 4가지는 Pc (2₁ 을 잃어 편극축이
바뀜 — 원하지 않는 쪽):

```
양이온 궤도 [0,1,2,3] : [0,3], [1,2]  -> P2_1     나머지 4개 -> Pc
산소 궤도  [4,5,10,11] : [4,11],[5,10] -> P2_1     나머지 4개 -> Pc
산소 궤도  [6,7,8,9]   : [6,8], [7,9]  -> P2_1     나머지 4개 -> Pc
```

**물질로 옮기면:**

| 채널 | 실현 | 비고 |
|---|---|---|
| 양이온 [0,3] ↔ [1,2] | 규칙배열된 Hf₂Zr₂O₈ (= 정렬 HZO, x=0.5) | HZO 는 이 분야 표준 물질 |
| 산소 [4,11] ↔ [5,10] | ¹⁶O/¹⁸O 규칙 동위원소 배열 | 힘상수 불변 → 본 계산이 **정확** |
| 산소 [6,8] ↔ [7,9] | 3배위 O 자리 선택적 N/F 치환, 규칙적 O 공공 | 전하보상 필요 |

세 채널 모두 **셀 크기를 바꾸지 않는다.** 초격자·주기 변조와 달리 BZ folding 이
없으므로 Weyl 위치가 재라벨링으로 흐려지지 않는다.

## 3. 핵심 결과 — Γ–Z 위의 nodal line 이 Weyl 로 바뀐다

### 3.1 Pca2₁ 에 이미 있는 것

거울면 `k1 = 0` 안(2차원 (k2,k3) 공간)에서는 밴드가 거울 고유값으로 라벨되므로
교차가 **선**을 이룬다. 그 nodal line 이 Γ–Z 를 지난다:

```
k1=0, k2=0.00 : gap 1.2e-4 at k3=0.2185     <- Gamma-Z 위
k1=0, k2=0.01 : gap 7.3e-5 at k3=0.2199
k1=0, k2=0.03 : gap 1.3e-4 at k3=0.2298
k1=0, k2=0.06 : gap 8.4e-5 at k3=0.2579
k1=0, k2=0.10 : gap 5.5e-5 at k3=0.3072      (격자 간격 1e-4 한계)
```

χ = 0 이라 위상적으로 무의미. 저장소 기존 메모의 "표준 경로 위 gap=0 은 거울면
nodal line 이라 무의미하다"가 바로 이것이다.

### 3.2 glide 를 깨면

같은 계산을 P2₁ 질량 배열로:

```
k1=0, k2=0.00 : 9.6e-5   <- 살아남음 (정밀화하면 9.8e-10)
k1=0, k2=0.01 : 2.0e-3   <- 열림
k1=0, k2=0.03 : 5.4e-3
k1=0, k2=0.06 : 8.6e-3
k1=0, k2=0.10 : 1.0e-2
```

**선이 gap 을 열고 점 하나로 수축한다.** 살아남는 점은 `k2 = 0`, 즉 C2·T 가
보호하는 유일한 자리다. 그리고 거울이 없어졌으므로 χ 는 더 이상 0 이 아니다.

### 3.3 두 채널을 섞어 정확히 Γ–Z 위에 고정

채널 하나만 켜면 그 점이 세기에 비례해 k1=0 에서 밀려난다:

```
dk1/d(양이온 delta) = +0.0006772 /amu
dk1/d(산소  delta)  = -0.0286240 /amu       (산소 쪽이 42배 강하다)
```

부호가 반대이므로 비율로 상쇄할 수 있다. 조건은 1개(k1=0), 자유도는 1개(비율)이라
항상 풀린다. `--mode solve` 결과:

```
양이온 delta = 4.0 amu, 산소 delta = 0.098516 amu   (상쇄비 0.02366)
공간군 = P2_1                                       (spglib, 4종 원소로 데코레이션)
Weyl k = (0.000000000, 0, 0.2184358)
gap    = 9.8e-10 THz
chirality = -1.000                                  (구 반지름 무관)
```

k2=0 평면 전체의 노드 목록 (P2₁, 두 채널):

```
k=(-0.0968880, 0, 0.1605573)  chi=-1     <- 기존 Weyl (거울 짝이 풀려 독립 이동)
k=( 0.0000000, 0, 0.2184358)  chi=-1     <- 새로 켜진, Gamma-Z 위의 Weyl
k=(+0.0980263, 0, 0.1614509)  chi=+1
```

## 4. 왜 "기존 Weyl 을 옮기는" 접근은 막혀 있는가

참고로, 기존 (0.0975, 0, 0.1610) Weyl 을 경로 위로 끌고 가는 시도는 **원리적으로**
막혀 있다는 것도 확인했다.

- 그 Weyl 의 거울 짝은 (−0.0975, 0, 0.1610) 이고 **χ 가 반대**다. k1=0 에 올리려면
  둘이 같은 자리에서 만나야 하는데, 반대 부호는 만나면 **소멸**한다.
- 질량을 균일하게 낮춰(strain 과 독립인 제2의 Pca2₁-보존 손잡이) 밀어보면
  m̄ ≈ 125–130 amu 에서 정확히 k1 = 0 에서 소멸한다. 기존 SUMMARY 의 "ray 는
  거울면에서 태어나 거울면에서 죽는다"를 **완전히 다른 섭동으로 독립 재현**한 셈이다.
- glide 를 깨도 이 쌍은 여전히 만나면 죽는다. glide breaking 이 하는 일은 소멸
  지점을 k1=0 에 **고정하지 않게** 만드는 것이지, 소멸 자체를 막는 게 아니다.

그래서 답은 그 Weyl 이 아니라 **nodal line 쪽**이다. nodal line 은 짝이 없다
(자기 자신이 χ=0 인 선). 켜기만 하면 되고 옮길 필요가 없다.

## 5. 부수적으로 정정되는 것 — rank-1 은 대칭 정리가 아니다

기존 SUMMARY 2절은 strain 응답 행렬이 rank-1 이라 "어떤 (ε_a, ε_c) 조합도 Weyl 을
고정된 직선 밖으로 못 보낸다"고 결론지었다. 이건 **대칭이 강제하는 게 아니라 그
2매개변수 족(族)의 성질**이다. 반례를 하나 만들었다:

```
strain ray 방향            :  43.4°   (k1,k3) 평면에서
질량 손잡이 방향 (O 무거워짐): 175.6°
질량 손잡이 방향 (Hf 무거워짐): -2.0°
```

**약 132° 어긋난다.** 즉 Pca2₁ 을 보존하는 섭동에 대한 노드의 응답은 본질적으로
rank-1 이 아니며, **대칭을 보존하는 세 번째 손잡이 아무거나** 하나만 있으면 평면
안 2차원 제어가 복원된다. 후보:

1. **편극축 방향 변형 ε_b** — 기존 4개 구조에서 편극축은 전부 자유 relax 였다
   (SUMMARY 표에도 "편극축(자유)"로 적혀 있다). 즉 A 행렬은 ε_b 가 Poisson 으로
   종속된 2차원 족에서만 뽑은 것이다. ε_b 를 고정(clamped)한 계산 한 점이면 판정된다.
   **비용 대비 정보량이 가장 큰 다음 계산.**
2. **조성 x (Hf₁₋ₓZrₓO₂)** — 대칭을 전혀 안 깨는 연속 손잡이. 질량만 바꿔도
   Hf→Zr 극단에서 노드가 Γ 까지 끌려가므로 (아래) 실제 감도는 매우 클 것이다.
3. 온도/비조화 (SSCHA) — 대칭 보존.

참고로 질량만 Hf→Zr(91.22 amu)로 바꾸면 노드가 Γ 로 끌려가 소멸한다
(gap 5.6e-5). 조성이 아주 센 손잡이라는 뜻이다.

## 6. 한계 (반드시 같이 읽을 것)

- **질량만 바꾼 모형이다.** 힘상수와 Born charge 는 Pca2₁ 대칭값으로 고정돼 있다.
  - ¹⁶O/¹⁸O 같은 **동위원소 규칙배열에는 정확**하다 (Born-Oppenheimer).
  - Hf/Zr **화학 규칙배열에는 하한**이다. 실제로는 힘상수·Born charge 도 P2₁ 로
    낮아지므로 glide breaking 이 훨씬 강하고, 3.3절의 상쇄비도 달라진다.
  - 단, 3절의 메커니즘(거울 nodal line → C2T 보호점 하나로 수축 → χ≠0)은 순수
    대칭 논증이라 이 근사와 무관하다.
- **k1 = 0 은 대칭이 고정해 주는 자리가 아니다.** P2₁ 에서는 codimension-1 조건이라
  손잡이 하나로 맞춰야 한다(그래서 채널 2개를 썼다). 대신 정확히 안 맞아도 Weyl 은
  Γ–Z **근처**에 남고, 그 상태로도 표준 스캔선에서 보인다.
- **chirality 부호 규약**: 본 스크립트의 Berry flux 는 Simphony `WeylChirality_calc`
  와 전체 부호가 반대다. 크기와 상대 부호는 일치함을 확인했다
  (pristine (±0.0975,0,0.1610) 에서 ∓1, k3=½ 평면에서 0, 구 반지름 0.002/0.004/0.008
  모두 동일).
- 이 저장소의 기존 경고 — 구조들이 서로 다른 조건으로 relax 되었고 parent/mirror
  FORCE_SETS 가 0.03~0.14 THz 어긋난다는 것 — 은 그대로 유효하다. 다만 본 절의
  결과는 **한 데이터셋(`pristine_mirror`) 안에서만** 비교하므로 그 오염을 타지 않는다.
