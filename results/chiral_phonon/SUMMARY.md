# 포논 원편광과 모드 각운동량 (chiral phonon)

계기: 진동 패턴 애니메이션에서 "O 가 원을 그리고 그 평면이 계속 도는
세차운동처럼 보인다" 는 관찰. 마그논인지 물었는데, 마그논은 아니고
**포논 원편광**이다.

## 0. 마그논은 없다

HfO₂ 는 Hf⁴⁺ (5d⁰) + O²⁻ (2p⁶) 닫힌 껍질이라 국소 모멘트가 없는 비자성
절연체다. 마그논 가지가 존재하지 않는다. 이 프로젝트의 `FORCE_SETS`/`BORN`
자체도 스핀 없는 계산 산물이라 자기 정보가 들어 있지 않다.
(Berry curvature·Chern 수를 다루는 **방법론**은 Weyl magnon 문헌과 공통이므로
계산 기법 참고용으로는 쓸모가 있지만, 이 물질에 마그논은 없다.)

## 1. 무엇을 재는가

질량가중 고유벡터 `e_j = a_j + i b_j` 에 대해 원자 j 의 변위는

    u_j(t) = Re[ (e_j / √m_j) e^{-iωt} ]

이고, 이는 **a_j 와 b_j 가 張하는 고정된 평면** 안의 타원을 그린다.
시간평균 각운동량은 `<l_j> = 2 (a_j × b_j)` (ħ 단위, 질량가중 기준),
원형도는 `circ = 2|a×b| / (|a|²+|b|²)` — 1 이면 완전한 원, 0 이면 직선 진동.

도구: `scripts/mode_angular_momentum.py`

## 2. "O 가 원을 그린다" — 맞다

band 17–18 Weyl 노드에서 0.002 1/Å 벗어난 점 (`ellipse_near_weyl_node.log`):

| | 원형도 범위 | 진폭 |
|---|---|---|
| O (8개) | **0.57 ~ 0.94** | |a|,|b| ~ 0.15–0.41 |
| Hf (4개) | 0.72 ~ 0.97 | |a|,|b| ~ 0.04–0.10 |

Hf 도 원을 그리지만 진폭이 O 의 1/5 수준이라 눈에 안 띈다.

## 3. "평면이 돈다" — 한 모드 안에서는 일어날 수 없다

위 식에서 타원면은 시간에 대해 **고정**이다. 인상의 출처는 셋 중 하나이고,
재보니 (1) 과 (2) 다.

1. **원자마다 타원면이 다르다.** 노드 근방 band 17 에서 타원면 법선이
   원자별로 **최대 89.1°, 평균 56.0°** 까지 벌어진다 (band 18 은 89.8° / 57.9°).
   집단 운동을 눈으로 따라가면 평면이 도는 것처럼 보인다.
2. **여러 단위포를 같이 그리면 실공간에서 나선이 된다.** `q·R` 위상 때문에
   셀마다 타원면 위상이 advance 한다. 원편광 포논이 진행할 때의 진짜 모습이다.
3. **축퇴 근처 두 모드의 맥놀이 — 아니다.** 노드에서 Δω ≈ 0.003 THz 대
   ω ≈ 10.09 THz 라 진동 약 3,400 주기에 한 번 도는 수준이다.

## 4. 쓸모 있는 부분 — 노드를 돌면 두 밴드가 각운동량을 맞바꾼다

**원편광 자체는 이 결정에서 흔하다.** 노드와 무관한 일반점
`(0.30, 0.25, 0.18)` 에서도 원형도 0.15~0.95, |L| ~ 0.2 ħ 가 나온다
(`ellipse_generic_k.log`). 원운동을 봤다는 것만으로는 위상적 의미가 없다.

의미 있는 건 **교환**이다. band 17–18 Weyl 노드를 편극평면 안에서 반지름
0.004 1/Å 로 한 바퀴 돌면 (`L_around_weyl_node.log`):

| 각도 | L(band 17) [ħ] | L(band 18) [ħ] |
|---|---|---|
| 0° | (+0.130, 0, −0.180) | (−0.075, 0, −0.028) |
| 45° | (+0.064, 0, −0.317) | (−0.010, 0, +0.112) |
| 90° | (−0.028, 0, −0.266) | (+0.082, 0, +0.065) |
| 135° | (−0.069, 0, −0.156) | (+0.124, 0, −0.041) |
| **180°** | **(−0.077, 0, −0.027)** | **(+0.133, 0, −0.170)** |
| 225° | (−0.006, 0, +0.113) | (+0.062, 0, −0.313) |
| 270° | (+0.088, 0, +0.060) | (−0.032, 0, −0.264) |
| 315° | (+0.125, 0, −0.043) | (−0.069, 0, −0.165) |

180° 에서 두 값이 0° 의 상대 값과 뒤바뀌어 있다. χ = ±1 이 Berry flux 숫자만이
아니라 **모드 각운동량의 교환**으로 나타난다는 뜻이고, 원편광 IR/Raman 이나
포논 열홀 쪽 측정 언어로 연결된다.

노드로 접근할 때 L 은 발산하지 않고 수렴한다 (0.05 → 0.0005 1/Å 에서
band 17 이 (+0.113,0,−0.223) → (+0.131,0,−0.176)). 두 밴드의 합
`L17 + L18` 도 (+0.055, 0, −0.20) 근처로 매끄럽다 — 갈라지는 것은
**어느 밴드가 어느 값을 갖는가** 뿐이다.

## 5. 대칭 확인 — 기존 결과와 맞물린다

**편극평면(`k_P = 0`) 안에서 편극축 성분 `L_polar` 가 정확히 0 이다**
(위 표의 가운데 성분이 전부 0.000). `results/parent_pristine/SUMMARY.md` §18 의
"편극평면에서 Ω_c ≡ 0" 과 같은 반유니타리 대칭이 각운동량에도 걸리는 것으로
보인다. (여기서는 **측정 사실**로만 적는다 — 유도는 따로 하지 않았다.)

Γ–Z 선 위에서는 한 발 더 나가 **총 L = 0** 이다 (`ellipse_on_GZ.log`).
개별 원자는 여전히 원형도 0.23~0.73 으로 돌고 있고, 대칭 짝끼리 상쇄된다.

## 6. bulk 배경 — "노드 말고 주변에 방해물이 있나"

BZ 전체를 Γ 피한 MP 20×20×20 = 8000 q점 × 36모드로 훑었다
(`scripts/bz_am_background.py`, 원자료 `bz_background_N20.log`).

### 6.1 여분의 가지는 없다

원자 12개 × 3 = **36**, phonopy 가 주는 가지 수도 **36**. 진동 자유도가 전부
포논으로 소진된다. 애니메이션에서 보이는 "세차"는 이 36개의 조합이지
숨어 있는 별도의 들뜸이 아니다. 마그논이든 무엇이든 셀 자리가 없다.

### 6.2 원편광 배경은 크고, 완벽하게 상쇄된다

|L| 분포 (ħ):

| 집합 | 중앙값 | 평균 | 90%분위 | 최대 |
|---|---|---|---|---|
| 전 36밴드 × 전 BZ | 0.136 | 0.169 | 0.332 | 0.933 |
| band 17, 18 만 | 0.113 | 0.125 | 0.234 | 0.332 |
| 노드 에너지 ±0.10 THz | 0.075 | 0.095 | 0.187 | 0.291 |

**결정 대부분이 돌고 있다.** 그런데 알짜는:

```
Σ L  = (-8.2e-15, +1.9e-13, +5.5e-14) hbar    Σ|L|  = 48595.7
Σ mu = (+3.6e-18, -2.5e-18, -7.4e-18) mu_B    Σ|mu| = 2.752
```

**10¹⁷ 분의 1 수준으로 지워진다.** 시간반전 `L(-q) = -L(q)` 때문이고,
격자에 ±q 짝이 다 들어 있으므로 이 값은 그 항등식의 검산이다. 평형에서
BZ 평균이 0 이라는 것은 격자와 무관한 일반론이다. 알짜 자화도, 자기 탐침에
걸릴 배경도 없다.

### 6.3 노드는 원편광에서 특별하지 않다 — 중요한 경고

노드 자신의 |L| 은 0.13~0.22 ħ 다. 같은 에너지대 배경의 중앙값 0.075,
90%분위 0.187 과 비교하면 **평범하거나 약간 위**일 뿐이다.

> **"원편광이니까 Weyl 이다" 는 성립하지 않는다.** 배경이 똑같이 chiral 하다.
> 판별자는 |L| 의 크기가 아니라 §4 의 **두 밴드가 한 바퀴 돌 때 값을 맞바꾼다**
> 는 쪽이다.

### 6.4 진짜 배경은 포논 자신이고, 그건 오히려 깨끗한 편이다

노드 에너지 10.0868 THz 주변에 BZ 전체에서 닿는 가지:

| 창 | 관여 밴드 | q점의 비율 |
|---|---|---|
| ±0.05 THz | 17, 18, 19 | 9.6% |
| ±0.10 THz | 17, 18, 19 | 16.8% |
| ±0.25 THz | 17, 18, 19 | 33.2% |
| ±0.50 THz | 17, 18, 19, 20 | 51.0% |

**36개 중 3개만** 그 에너지에 산다 (±0.5 THz 까지 넓혀야 20번이 들어온다).
에너지 분해 측정에는 유리한 창이다.
`results/parent_pristine/SUMMARY.md` §17.4 의 "밴드 17/18/19 만 관여" 와 일치한다.

## 7. 강유전 쪽 대응물 — ferron

"자성절연체는 마그논으로 스핀류를 나른다는데 강유전체에는 대응물이 없나" 에 대한 답.

| | 자성절연체 | 강유전절연체 (이 물질) |
|---|---|---|
| 질서변수 | M | P |
| 요동의 양자 | 마그논 | **극성 광학포논** ("ferron") |
| **별도의 가지인가** | **그렇다** (스핀은 격자와 별개 자유도) | **아니다** (질서변수가 격자 그 자체) |
| 나르는 것 | 스핀 각운동량 | 전기쌍극자 / 분극 |
| 대칭 | T-홀수, 축벡터 | T-짝수, 극벡터 |

§6.1 의 "36 = 3×12, 여분의 가지 없음" 이 여기서 설명된다. 자석에서는 스핀이
격자와 독립이라 마그논이 포논 **위에** 더 얹히지만, 변위형 강유전체에서는
분극파가 이미 있는 36개 중 하나다.

(ferron 이라는 명명은 Bauer–Uchida 계열 2021년 무렵 제안으로 기억하나
**출처는 확인하지 않았다.**)

### 7.1 물질 수준에서는 영향이 압도적이다

Γ 에서 모드별 이온 유전기여 (`eps_ion_and_dipole_background.log`):

```
eps^ion = diag(18.09, 16.47, 14.06)   평균 16.21
```

`ε_∞ ≈ 4~5` 를 더하면 ε ≈ 20~21 로 HfO₂ 의 알려진 high-k 값(~20~25)과 맞는다.
**유전상수의 75~80% 가 격자(ferron) 기여다.** 기여 상위는
band 12 (7.13 THz) 22.4%, band 15 (8.17) 15.0%, band 20 (10.23) 14.7%,
band 22 (11.61) 12.3%, band 23 (11.91) 10.8%.

이 성분은 이미 계산에 들어 있다 — `patch/apply_simphony_loto_fix.py` 의
LO-TO 수정 7건이 바로 이 항을 제대로 세는 작업이었다.

### 7.2 Weyl 노드에 대해서는 새 도구가 아니다

모드 쌍극자 `p = A(ω)·Σ_j Z*_j e_j/√m_j` 를 BZ 전체(12³×36)에서 재고 노드와 대조했다.

| | 중앙값 | 90%분위 | 최대 |
|---|---|---|---|
| 쌍극자 원형도, 전 밴드 × 전 BZ | **0.418** | **0.851** | **0.9995** |
| band 17, 18 | 0.366 | 0.739 | 0.997 |
| 노드 에너지 ±0.10 THz | 0.337 | 0.750 | 0.997 |
| **노드 근방 band 17 실측** | **0.926** | | |

> **정정.** 노드의 회전 쌍극자 원형도 0.926 은 처음에 인상적으로 보였으나,
> 배경 90%분위가 0.851, 최대가 0.9995 다. **회전 쌍극자는 이 결정에서 흔하다.**
> §6.3 의 |L| 경고가 쌍극자에도 그대로 적용된다 —
> **"회전 쌍극자니까 Weyl" 은 성립하지 않는다.**

극성 크기도 특별하지 않다. `|p|` 는 band 17/18 중앙값 0.139 e·Å 로 전체
중앙값 0.097 보다 약간 높지만, 노드 에너지대만 보면 **0.063 으로 평균 이하**다.
Γ 에서 band 17/18 은 유전기여 상위 10위 안에 들지 못하고, 노드 에너지대
±0.5 THz 전체를 합쳐도 ε^ion 의 **16.5%** 이며 그나마 대부분 band 20 이 낸 것이다.

### 7.3 정리

- **물질 이해에는 큰 축** (유전상수의 4/5), 그리고 **이미 지불한 값** (LO-TO 패치).
- **노드 판별에는 무용**. 변위형 강유전체에서 ferron 은 극성 광학포논의
  다른 이름이고, 이름을 바꾼다고 새 자유도나 새 결합이 생기지 않는다.
- ferron 개념이 실제로 일하는 자리(열구배 분극 수송)는 (a) 실험적 입지가
  스핀 제벡보다 훨씬 얇고, (b) 분극은 T-짝수 극벡터라 역스핀홀 같은 전기적
  읽기 사슬이 복사되지 않으며, (c) **분극 전류는 bulk 수송량이라 노드 하나를
  분해하지 못한다.**

> **노드를 가리키는 판별자는 여전히 §4 의 "한 바퀴 돌 때 두 밴드가 값을
> 맞바꾼다" 하나다.** |L| 도, |p| 도, 원형도도 배경과 구별되지 않는다.
> 크기가 아니라 **교환**이다.
