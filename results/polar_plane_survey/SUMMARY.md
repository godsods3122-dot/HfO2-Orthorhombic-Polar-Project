# 편극 평면 Weyl 전면 조사 — 다섯 구조 (Simphony)

탐색은 Simphony `BulkGap_cube_calc`(패치본), 전하는 Simphony `WeylChirality_calc`.
phonopy 는 교차검증에만 사용.

## 0. 결과

편극축=0 평면 전체를 401×401(간격 0.00125)로 훑었다.

| 구조 | 압축 평균 | 평면 | 1위 후보 | dw (THz) | 2위 격차 | 판정 |
|---|---|---|---|---|---|---|
| **parent_pristine** | 0 % | k3=0 | (0.14625, 0.07125, 0) | **7.20e-04** | 17배 | **Weyl** |
| **m1_mirror** | −0.77 % | k2=0 | (0.06375, 0, 0.13000) | **1.38e-03** | 9배 | **Weyl** |
| parent_m1_old | −1.00 % | k2=0 | (0.48750, 0, 0.48750) | 1.13e-02 | — | 없음 |
| m2.5_mirror | −2.5 % | k3=0 | (0.48750, 0.48750, 0) | 6.30e-03 | — | 없음 |
| m3_mirror | −3.0 % | k3=0 | (0.48750, 0.48750, 0) | 3.07e-03 | — | 없음 |

**판정 기준**: Weyl 이 있는 두 구조는 1위가 **일반위치**이고 2위와 한 자릿수 배수 차이가
난다. 없는 세 구조는 **1위 자체가 거울선/모서리**(χ=0 강제)이고 일반위치 후보가 그 아래로
내려오지 않는다.

→ **편극 평면 Weyl 의 소멸 임계는 −0.77 % 와 −1.00 % 사이다.**
phonopy 조밀 스캔과 Simphony BulkGap 이 **서로 독립적으로 같은 답**을 냈다.


## 2. 이번에 걸러낸 함정 세 가지 (재현할 때 반드시 확인)

1. **`LOTO_method` 누락** — `input.py` 는 이 줄을 쓰지 않아 기본값 `'qe'` 로 떨어진다.
   phonopy 유래 hr.dat 과 Ewald 분할이 달라 **밴드 주파수부터 0.03 THz 어긋나는데
   에러 없이 그럴듯한 숫자가 나온다.** m1_mirror 에서 1위 후보가
   (0.0825, 0, 0.1375)/dw=1.02e-3 로 나왔다가, 넣고 다시 돌리니
   (0.06375, 0, 0.13000)/dw=1.38e-3 으로 **실제 노드가 복구**됐다.
   `scripts/bulkgap_scan.py` 가 이제 강제로 써넣는다.
2. **`Nk2` 부족** — `Nk2` 는 구면 Wilson loop 개수다. 무른 노드는 적도 근처에서 WCC 가
   빨라 loop 이 성기면 언랩이 반대로 가고 **조용히 0** 이 나온다. 200 이하 금지, 800 이상.
3. **대칭면 여유** — 자동값(격자간격 1.5배)은 조밀 격자에서 부족하다. 401×401 이면
   0.0019 인데 거울선이 0.0025 지점에서 샌다. `--tol 0.012` 로 올려서 재해석할 것
   (`--no-run` 이면 재계산 없이 다시 해석한다).

## 3. 폐기/철회한 것

- **Γ-S 경로** — 표준 고대칭 경로가 아니므로 폐기.
- **"KCUBE 얇은 벡터가 두 번째면 격자가 깨진다"** — 오진. 벡터를 재배열해도 같은 점
  집합이라 결과가 바뀔 수 없다. 진짜 원인은 위 2절 1번이었다.

## 재현

```bash
python3 scripts/bulkgap_scan.py --dir <work> --src <source> \
        --origin 0 0 0 --span 0.5 0.5 0.001 -N1 401 -N2 401 -N3 2 \
        --thresh 0.05 --tol 0.012          # 편극축이 k2 면 --span 0.5 0.001 0.5 로
# 그다음 pn.in 에 WEYL_CHIRALITY 카드(4점 궤도) + Nk1=240 Nk2=801 로 pn.x
```
