# parent–mirror 를 잇는 길: 180° 도메인 배열 — 조성도 strain 도 안 건드림

`scripts/domain_super.py` 로 계산. 구조 `source/pristine_mirror`
(Pca2₁, 편극축 = b(지표 1), 거울지표 = a,c(지표 0,2)).

각 도메인 내부는 **100% 원래 Pca2₁ HfO₂ 그대로**다. 치환도 변형도 없다.
바뀌는 것은 도메인 배열(= 분극 상태)뿐이고, 그건 전기장으로 쓰고 지울 수 있다.

---

## 0. 한 줄 요약

**분극 상태 자체가 대칭 손잡이다.**

| 분극 상태 | 벽 법선 | 초격자 공간군 | 반전 | 거울 | Weyl |
|---|---|---|---|---|---|
| 완전 분극 (단일 도메인) | — | Pca2₁ | 없음 | k1, k3 | 존재하나 표준 경로 전체에서 χ=0 강제 |
| 부분 분극 | **∥ a** | Pca2₁ | 없음 | k1, k3 | 그대로 (folding 만) |
| 부분 분극 | **∥ c** | **P2₁** | 없음 | **없음** | **표준 경로가 열린다** |
| 미분극 / 완전 보상 | ∥ a | Pbca | **있음** | k1,k2,k3 | **전멸** |
| 미분극 / 완전 보상 | ∥ c | P2₁/c | **있음** | k2 | **전멸** |

즉 **벽 법선이 c 인 180° 벽을 불균등하게 넣으면 P2₁ 이 된다** — 앞서 Zr 규칙배열로
얻으려 했던 바로 그 부분군을, 화학 조성을 전혀 안 건드리고 얻는다.

---

## 1. 왜 c 방향만 되는가 (병진 성분 회계)

Pca2₁ 의 두 glide 는 병진 성분에 **둘 다 c 방향 ½** 을 갖는다:

```
op2  R=diag( 1, 1,-1)  t=(0, ½, ½)   glide ⊥ c
op3  R=diag(-1, 1, 1)  t=(0, 0, ½)   glide ⊥ a
op1  R=diag(-1, 1,-1)  t=(0, ½, 0)   2₁ screw ∥ b (편극축)  ← c 성분 없음
```

- 변조 방향 ∥ **c** → 두 glide 의 c 방향 ½ 병진이 도메인 무늬를 가로지른다
  → **둘 다 깨짐**. 2₁ 은 c 성분이 없어 **살아남음** → **P2₁**.
- 변조 방향 ∥ **a** → 어느 glide 도 a 성분이 없다 → **아무것도 안 깨짐** → Pca2₁.

원하는 것(거울만 제거, 2₁ 유지)이 정확히 c 변조에서 나온다. 우연이 아니라
공간군 병진 성분이 정해 준다.

> 축 규약은 구조마다 다르다. 다른 구조에 적용하기 전에 반드시
> `weyl_scan.py --mode sym` 으로 확인할 것. 일반 규칙은
> **"두 glide 의 병진이 공유하는 축 방향으로 변조하라"**.

## 2. 벽의 물리적 타당성

- 벽 법선 ⊥ 편극축(b) → **벽면이 편극축을 포함** → 결합전하 없음, 전기적으로 중성.
  180° 벽으로서 물리적으로 선호되는 배향이다.
- 편극축(b) 방향 변조 = head-to-head. 이상화 구조의 최소원자거리 **0.087 Å** 로
  비물리적. 정전기적으로도 배제된다. → **b 변조는 논외.**
- a·c 변조는 최소원자거리 2.023 Å (벌크 2.025 Å) 로 기하학적으로 멀쩡하다.

## 3. 미분극 상태는 Weyl 을 **전멸**시킨다

도메인 폭이 정확히 같으면 초격자가 **반전대칭**을 얻는다 (Pbca / P2₁/c).
포논은 스핀 없는 계라 반전 + 시간역전이 함께 있으면 Berry curvature 가
**전 BZ 에서 항등적으로 0** 이다. Weyl point 가 하나도 존재할 수 없다.

이건 검증 가능한 예측이자 응용 자체다:

> **분극이 Weyl 포논의 on/off 스위치다.**
> 미분극 필름 → Weyl 없음. 분극을 넣으면 → Weyl 켜짐.
> 부분 분극 + c 벽 → Weyl 이 켜지고 **표준 고대칭 경로 위로 올라온다.**

강유전성을 깨는 게 아니라 **강유전성 자체를 손잡이로 쓴다.**

## 4. 페이오프 — `results/order_break/SUMMARY.md` 와 같은 메커니즘

P2₁ 이 되면 앞 문서 3절의 메커니즘이 그대로 발동한다. 요지만 옮기면:

- Pca2₁ 의 거울면 `k1=0` 안에는 band17–18 **nodal line** 이 있고 Γ–Z 를
  `k3 = 0.2185` 에서 가로지른다. 거울 때문에 **χ = 0** 이라 무의미했다.
- 거울이 없어지면 그 선은 gap 이 열리고, `k2 = 0`(C2·T 보호) 점 하나만 살아남아
  **χ = ±1 의 진짜 Weyl** 이 된다. 질량 규칙배열로 만든 P2₁ 모형에서 확인:
  `k=(0, 0, 0.2184358)`, gap 9.8e-10 THz, **χ = −1**, 10.3346 THz (42.74 meV).
- 도메인 초격자의 Γ–Z 는 c 방향으로 N 배 접히지만 `k1=k2=0` 은 그대로라
  **접힌 뒤에도 Γ–Z 위에 남는다**.

기존 (0.0975, 0, 0.1610) Weyl 을 옮기는 게 아니라, 이미 경로 위에 있던 것을 켜는
것이므로 이동 거리가 0 이고 strain 도 필요 없다.

## 5. 한계 — 반드시 같이 읽을 것

- **대칭은 증명됐고 크기는 아직이다.** 공간군이 P2₁ 인 것은 도메인 폭 비율과
  무관하게 엄밀하다. 그러나 **거울이 깨지는 세기는 벽 밀도(∝ 1/도메인 폭)에 비례**한다.
  HfO₂ 의 180° 벽은 1–2 단위셀로 매우 얇고 도메인은 통상 10–30 nm 이므로 벽
  부피분율은 대략 3–10% 다. 0 은 아니지만 작다. Γ–Z Weyl 의 gap 및 nodal line 이
  얼마나 벌어지는지는 **도메인벽 초격자 DFT 로 직접 재야 한다.**
- 이 문서의 구조는 **이완하지 않은 이상화 벽**이다. 실제 벽은 이완하지만
  이완이 도메인 무늬의 주기성을 깨지 않는 한 공간군 결론은 그대로다.
- 실제 필름은 주기적 배열이 아니라 폭 분포를 갖는다. 그래도 "거울 조작이
  전체적으로 성립하지 않는다"는 결론은 더 강해질 뿐 약해지지 않는다
  (무질서는 대칭을 복원하지 않는다). 다만 접힘(folding)에 기반한 논의는
  주기성이 없으면 성립하지 않으므로 쓰지 않았다 — 위 결론은 folding 에
  의존하지 않는다.
- 레포의 기존 경고(구조별 relax 조건 불일치, parent/mirror FORCE_SETS 가
  0.03–0.14 THz 어긋남)는 그대로 유효하다. 본 절은 **대칭 계산만** 하므로
  그 오염을 타지 않는다.
