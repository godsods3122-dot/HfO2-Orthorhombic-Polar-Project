# parent–mirror 를 잇는 길: 180° 도메인 배열 — 조성도 strain 도 안 건드림

`scripts/domain_super.py` 로 계산. 구조 `source/pristine_mirror`
(Pca2₁, 편극축 = b(지표 1), 거울지표 = a,c(지표 0,2)).

각 도메인 내부는 **100% 원래 Pca2₁ HfO₂ 그대로**다. 치환도 변형도 없다.
바뀌는 것은 도메인 배열(= 분극 상태)뿐이고, 그건 전기장으로 쓰고 지울 수 있다.

## 0. 한 줄 요약

**분극 상태 자체가 대칭 손잡이다.**

| 분극 상태 | 벽 법선 | 초격자 공간군 | 반전 | 거울 | Weyl |
|---|---|---|---|---|---|
| 완전 분극 (단일 도메인) | — | Pca2₁ | 없음 | k1, k3 | 존재하나 표준 경로 전체에서 χ=0 강제 |
| 부분 분극 | **∥ a** | Pca2₁ | 없음 | k1, k3 | 그대로 (folding 만) |
| 부분 분극 | **∥ c** | **P2₁** | 없음 | **없음** | **표준 경로가 열린다** |
| 미분극 / 완전 보상 | ∥ a | Pbca | **있음** | k1,k2,k3 | **전멸** |
| 미분극 / 완전 보상 | ∥ c | P2₁/c | **있음** | k2 | **전멸** |

즉 **벽 법선이 c 인 180° 벽을 불균등하게 넣으면 P2₁ 이 된다** — 앞서 Zr 규칙배열로
얻으려 했던 바로 그 부분군을, 화학 조성을 전혀 안 건드리고 얻는다.

## 1. 왜 c 방향만 되는가 (병진 성분 회계)

Pca2₁ 의 두 glide 는 병진 성분에 **둘 다 c 방향 ½** 을 갖는다:

```
op2  R=diag( 1, 1,-1)  t=(0, ½, ½)   glide ⊥ c
op3  R=diag(-1, 1, 1)  t=(0, 0, ½)   glide ⊥ a
op1  R=diag(-1, 1,-1)  t=(0, ½, 0)   2₁ screw ∥ b (편극축)  ← c 성분 없음
```

- 변조 방향 ∥ **c** → 두 glide 의 c 방향 ½ 병진이 도메인 무늬를 가로지른다
  → **둘 다 깨짐**. 2₁ 은 c 성분이 없어 **살아남음** → **P2₁**.
- 변조 방향 ∥ **a** → 어느 glide 도 a 성분이 없다 → **아무것도 안 깨짐** → Pca2₁.

원하는 것(거울만 제거, 2₁ 유지)이 정확히 c 변조에서 나온다. 우연이 아니라
공간군 병진 성분이 정해 준다.

> 축 규약은 구조마다 다르다. 다른 구조에 적용하기 전에 반드시
> `weyl_scan.py --mode sym` 으로 확인할 것. 일반 규칙은
> **"두 glide 의 병진이 공유하는 축 방향으로 변조하라"**.

## 2. 벽의 물리적 타당성

- 벽 법선 ⊥ 편극축(b) → **벽면이 편극축을 포함** → 결합전하 없음, 전기적으로 중성.
  180° 벽으로서 물리적으로 선호되는 배향이다.
- 편극축(b) 방향 변조 = head-to-head. 이상화 구조의 최소원자거리 **0.087 Å** 로
  비물리적. 정전기적으로도 배제된다. → **b 변조는 논외.**
- a·c 변조는 최소원자거리 2.023 Å (벌크 2.025 Å) 로 기하학적으로 멀쩡하다.

## 3. 미분극 상태는 Weyl 을 **전멸**시킨다

도메인 폭이 정확히 같으면 초격자가 **반전대칭**을 얻는다 (Pbca / P2₁/c).
포논은 스핀 없는 계라 반전 + 시간역전이 함께 있으면 Berry curvature 가
**전 BZ 에서 항등적으로 0** 이다. Weyl point 가 하나도 존재할 수 없다.

이건 검증 가능한 예측이자 응용 자체다:

> **분극이 Weyl 포논의 on/off 스위치다.**
> 미분극 필름 → Weyl 없음. 분극을 넣으면 → Weyl 켜짐.
> 부분 분극 + c 벽 → Weyl 이 켜지고 **표준 고대칭 경로 위로 올라온다.**

강유전성을 깨는 게 아니라 **강유전성 자체를 손잡이로 쓴다.**

## 4. 페이오프 — `results/order_break/SUMMARY.md` 와 같은 메커니즘

P2₁ 이 되면 앞 문서 3절의 메커니즘이 그대로 발동한다. 요지만 옮기면:

- Pca2₁ 의 거울면 `k1=0` 안에는 band17–18 **nodal line** 이 있고 Γ–Z 를
  `k3 = 0.2185` 에서 가로지른다. 거울 때문에 **χ = 0** 이라 무의미했다.
- 거울이 없어지면 그 선은 gap 이 열리고, `k2 = 0`(C2·T 보호) 점 하나만 살아남아
  **χ = ±1 의 진짜 Weyl** 이 된다. 질량 규칙배열로 만든 P2₁ 모형에서 확인:
  `k=(0, 0, 0.2184358)`, gap 9.8e-10 THz, **χ = −1**, 10.3346 THz (42.74 meV).
- 도메인 초격자의 Γ–Z 는 c 방향으로 N 배 접히지만 `k1=k2=0` 은 그대로라
  **접힌 뒤에도 Γ–Z 위에 남는다**.

기존 (0.0975, 0, 0.1610) Weyl 을 옮기는 게 아니라, 이미 경로 위에 있던 것을 켜는
것이므로 이동 거리가 0 이고 strain 도 필요 없다.

## 5. 한계 — 반드시 같이 읽을 것

- **대칭은 증명됐고 크기는 아직이다.** 공간군이 P2₁ 인 것은 도메인 폭 비율과
  무관하게 엄밀하다. 그러나 **거울이 깨지는 세기는 벽 밀도(∝ 1/도메인 폭)에 비례**한다.
  HfO₂ 의 180° 벽은 1–2 단위셀로 매우 얇고 도메인은 통상 10–30 nm 이므로 벽
  부피분율은 대략 3–10% 다. 0 은 아니지만 작다. Γ–Z Weyl 의 gap 및 nodal line 이
  얼마나 벌어지는지는 **도메인벽 초격자 DFT 로 직접 재야 한다.**
- 이 문서의 구조는 **이완하지 않은 이상화 벽**이다. 실제 벽은 이완하지만
  이완이 도메인 무늬의 주기성을 깨지 않는 한 공간군 결론은 그대로다.
- 실제 필름은 주기적 배열이 아니라 폭 분포를 갖는다. 그래도 "거울 조작이
  전체적으로 성립하지 않는다"는 결론은 더 강해질 뿐 약해지지 않는다
  (무질서는 대칭을 복원하지 않는다). 다만 접힘(folding)에 기반한 논의는
  주기성이 없으면 성립하지 않으므로 쓰지 않았다 — 위 결론은 folding 에
  의존하지 않는다.
- 레포의 기존 경고(구조별 relax 조건 불일치, parent/mirror FORCE_SETS 가
  0.03–0.14 THz 어긋남)는 그대로 유효하다. 본 절은 **대칭 계산만** 하므로
  그 오염을 타지 않는다.

# 보론 — 국소 강유전성(메모리 동작)을 전제로 다시 본 경우

"HfO₂ 의 가치는 국소적으로 다른 편극을 쓰는 것" 이라는 전제를 넣으면 위 결론의
적용 범위가 갈린다. 스스로 드러내야 할 간극이 하나 있다.

## A. 주기성 간극 (앞 절의 한계)

**"공간군이 P2₁ 이다"는 주기적 도메인 초격자에 대해서만 뜻이 있다.** 대칭이 깨지는
것 자체는 벽 하나만 있어도 참이지만, Bloch 밴드·공간군·고대칭 경로라는 언어는
주기성을 전제한다.

메모리 소자의 도메인 무늬는 국소적으로 **쓰여진** 것이라 주기적이지 않다. 그리고
도메인 폭이 10–30 nm 면 도메인 **내부**는 지수적 정확도로 그냥 Pca2₁ 이다. 즉
소자 동작 상태에서는:

- 도메인 내부의 Weyl 은 여전히 표준 경로 위에서 χ=0 (아무 이득 없음)
- glide 파괴는 벽으로부터 ~1 nm 안쪽에만 국한

따라서 **"Weyl 을 Γ–Z 위에 얹는다"는 목표에는 주기적 분극(periodic poling)이
필요하다** — 메모리 동작 그 자체로는 안 된다. 이 둘은 다른 시료다.
(주기 분극은 PPLN 등에서 확립된 기술이고, HfO₂ 는 벽이 원자적으로 얇고 도메인이
수 nm 까지 작아지는 것으로 알려져 있어 유리한 쪽이다.)

## B. 벽 밀도 의존성은 **1차**다

두 채널 P2₁ 모형에서 glide 파괴 세기 λ 를 바꿔가며 nodal line 이 벌어지는 정도를
쟀다 (k1=0 은 계속 유지됨 — Weyl 은 Γ–Z 위에 그대로 있다):

| λ | Γ–Z 위 Weyl k1 | k2=0.03 | k2=0.06 | k2=0.10 |
|---|---|---|---|---|
| 0 | 0 | 2.6e-4 | 3.1e-4 | 1.8e-4 | ← 격자 해상도 바닥 (실제 0) |
| 0.10 | −2.7e-7 | 6.0e-4 | 9.1e-4 | 1.0e-3 |
| 0.25 | −6.4e-7 | 1.4e-3 | 2.2e-3 | 2.5e-3 |
| 0.50 | −1.0e-6 | 2.7e-3 | 4.3e-3 | 5.1e-3 |
| 1.00 | −1.0e-8 | 5.4e-3 | 8.6e-3 | 1.0e-2 |
| 2.00 | +1.6e-5 | 1.1e-2 | 1.7e-2 | 2.0e-2 |
| 4.00 | +1.7e-4 | 2.1e-2 | 3.4e-2 | 4.1e-2 |

**gap ∝ λ^0.963 — 1차다.** 그러므로 벽 부피분율 f = w/L (w ≈ 0.5 nm, L = 도메인 주기)
에 비례한다: L = 5 nm 면 f ≈ 10%, L = 20 nm 면 f ≈ 2.5%.

크기 감각: 질량만 바꾼 완전파괴(λ=4) 에서도 k2=0.06 에서 3.4e-2 THz = 0.14 meV 다.
**질량 모형은 하한**이고(실제 벽은 원자가 실제로 움직이는 구조적 불연속이라 훨씬 셈),
정확한 값은 도메인벽 초격자 DFT 로만 나온다. 다만 **χ = −1 이라는 위상 성질 자체는
섭동 크기와 무관하게 정확**하다 — 작아지는 것은 그것이 드러나는 에너지 눈금이다.

**측정 함의**: Γ–Z 선 위만 훑으면 Pca2₁ 이든 P2₁ 이든 **똑같이 보인다** (같은 k3
에서 교차). 차이는 선 밖에 있다 — 편극축 방향(k2)으로 벗어날 때 축퇴가
**유지되는가(nodal line, χ=0) 풀리는가(고립 Weyl, χ=±1)**. 따라서 1D 선 스캔이
아니라 **Γ–Z 주변 (k2, k3) 2D 맵**을 재야 한다.

## C. 두 도메인은 주파수가 완전히 같고 chirality 만 반대다

m_polar 는 Pca2₁ + 시간역전 궤도 안에서 k 를 제자리로 보내고 χ 만 뒤집는다.
(k1,−k2,k3) 는 TR·m⊥c·m⊥a 로 (k1,k2,k3) 와 이어져 있으므로 ω 는 같고, m_polar 는
거울이므로 χ 는 반대다. 따라서

> **ω_↑(k) = ω_↓(k) 는 모든 k 에서 정확히 성립하고, χ_↑(k) = −χ_↓(k) 이다.**

- 편극 비트는 **일반 포논 분광에는 원리적으로 안 보이고**, chirality 감응 측정
  (포논 각운동량, arc 손대칭성, 열홀 부호 등) 에만 보인다.
- 부수적으로 이건 **검증 기준**이다: parent 와 mirror 의 FORCE_SETS 는 모든 k 에서
  같은 주파수를 줘야 한다. 레포가 관측한 최대 0.14 THz 불일치는 물리가 아니라
  전적으로 DFT 설정 차이이며, 그 값이 그대로 설정 오차의 상한이다.

## D. arc 는 **전극 계면**에서만 나온다 (대칭 변경 불필요)

`scripts/arc_projection.py`. Weyl 궤도의 chirality 와 표면 BZ 투영:

```
k=(+0.097523, 0, +0.161028)  chi=+1
k=(+0.097523, 0, -0.161028)  chi=-1
k=(-0.097523, 0, +0.161028)  chi=-1
k=(-0.097523, 0, -0.161028)  chi=+1
```

| 계면 법선 | 투영면 | 투영점 알짜 χ | arc |
|---|---|---|---|
| ∥ a | (k2,k3) | 0, 0 | **없음** |
| ∥ c | (k1,k2) | 0, 0 | **없음** |
| **∥ b (편극축)** | (k1,k3) | +1, −1, −1, +1 | **있음 (4점)** |

반대 부호 Weyl 이 겹쳐 투영되면 알짜가 0 이라 arc 가 안 생긴다. 살아남는 배향은
**편극축에 수직인 계면 하나뿐**이고, 그게 바로 강유전 커패시터의 **전극 계면**이다.

두 가지가 따라온다.

1. **소자 구조를 아무것도 안 바꿔도 된다.** 전극 계면은 이미 거기 있고,
   pristine Pca2₁ 에서 arc 가 이미 존재한다. P2₁ 도 주기 분극도 필요 없다.
2. **중성 180° 도메인 벽(법선 a 또는 c)에는 이 계열의 arc 가 없다.** 벽 자체에
   위상 모드를 기대하는 직관은 이 밴드에서는 성립하지 않는다. (편극축 법선 벽은
   head-to-head 라 비물리적.) 다만 벽을 사이에 두고 χ 가 뒤집히므로 벽은 여전히
   chirality 계면이며, **일반위치 Weyl 계열**(m1/m3 에 존재, pristine 에는 없음)
   에서는 투영이 겹치지 않아 상황이 달라질 수 있다 — 미검증.
