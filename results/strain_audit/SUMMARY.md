# strain 감사 — m1_mirror 는 −1% 가 아니다 (그리고 비등방은 별개 문제다)

축 정체(편극축 = 2₁ 나사축, 나머지 둘 = 거울축)를 spglib 으로 맞춘 뒤 축별로 잰 값.
구조마다 축 지표 순서가 다르므로 **인덱스로 짝지으면 틀린다.**

## 1. 측정값

| | 거울축 변형률 | 평균 | 두 축 불일치 | 편극축(자유) |
|---|---|---|---|---|
| **m1_mirror** | −0.8438 %, −0.6868 % | **−0.766 %** | 0.157 %p | +0.514 % |
| **parent_m1_old** | −0.9126 %, −1.0791 % | **−0.996 %** | 0.167 %p | +0.737 % |

## 2. 두 가지를 분리해야 한다

### (a) 비등방(두 거울축 불일치)은 **양쪽 다 있다** — m1_mirror 만의 결함이 아니다

0.157 %p vs 0.167 %p 로 **거의 같다.** 즉 "동료가 준 m1_mirror 는 비등방이라 못 쓴다"는
진단은 성립하지 않는다. 이 정도 불일치는 이 워크플로 전체의 공통 특성이다.

### (b) 진짜 문제는 **크기**다 — m1_mirror 는 −1% 가 아니라 −0.77% 다

평균 −0.766 % 로, 명목 −1% 의 **77% 만 걸려 있다** (23% 가 빠졌다).
parent_m1_old 는 −0.996 % 로 사실상 정확히 −1% 다.

## 3. 결정적 검사 — "이게 어떤 기준의 −1% 인가?"

변형된 축 길이를 0.99 로 나누면 *만약 −1% 가 정확히 걸렸다면* 기준이었어야 할
무변형 길이가 나온다. 그것을 실제 무변형 파일과 비교한다:

| | 필요한 기준 | 실제 기준과의 차이 |
|---|---|---|
| **parent_m1_old** | 5.001365, 5.198876 | **+0.088 %, −0.080 %** |
| **m1_mirror** | 5.004764, 5.219463 | **+0.158 %, +0.316 %** |

- `parent_m1_old` 는 `parent_pristine` 의 −1% 로 **±0.09 % 안에서 일관**된다.
  즉 "−1% 를 걸고 셀을 고정했다"로 설명된다.
- `m1_mirror` 는 두 축이 **서로 다른 기준**(+0.158 % vs +0.316 %)을 요구한다.
  **어떤 단일 무변형 격자를 갖다 놔도 정확한 −1% biaxial 로 설명되지 않는다.**

부호도 다르다: parent 는 필요한 기준이 실제 기준을 사이에 두고 갈리는데(+0.09/−0.08,
= 잡음), mirror 는 **둘 다 같은 쪽으로 치우쳐 있다**(+0.16/+0.32, = 계통 편향).

## 4. 가장 일관된 해석

**strain 을 건 뒤 셀이 풀려서 되돌아갔다.** 셀을 고정(예: ISIF=2)하고 이온만 이완하면
거울축 길이는 정의상 정확히 −1.000 % 여야 한다. 실제로는 −0.84/−0.69 로 크기가 줄었고
계통적으로 한 방향이다 — 셀 자유도가 열려 있어(예: ISIF=3) 평형 쪽으로 일부 이완한
모습과 맞는다. `parent_m1_old` 는 그 이완이 없었거나 훨씬 적었다.

**단, 이것은 격자상수만으로 세운 가설이다.** 확정하려면 두 계산의 INCAR 에서
`ISIF`, `NSW`, `EDIFFG` 와, 변형 POSCAR 를 만들 때 쓴 기준 셀이 우리가 가진 pristine
파일과 같은지를 직접 봐야 한다.

## 5. 이게 결론을 바꾸는가 — 바꾼다. 그래서 중요하다

이 프로젝트에서 0.23 %p 는 무시할 수 있는 오차가 아니다.

- 편극축=0 Weyl 계열은 **−0.77 % 에서 살아 있고 −1.00 % 에서 죽는다**
  (양쪽 다 161×161 조밀 평면 스캔으로 확인. `results/parent_m1_old/SUMMARY.md` 4절).
  즉 **소멸점이 정확히 이 두 값 사이에 있다.**
- 기존 감도 분석은 격자 0.09 % 차이가 Weyl 좌표를 0.063(환산) 움직인다고 했다
  — 좌표 자체의 33 % 다.

따라서 m1_mirror 를 "−1% 점"으로 쓰면 소멸점을 놓치고, "−0.77% 점"으로 쓰면
소멸 구간을 좁히는 **유효한 데이터**가 된다.

## 6. 권고

1. **명목값이 아니라 실측 변형률로 라벨링한다.** m1_mirror → `−0.77%`,
   parent_m1_old → `−1.00%`. 표와 그림의 축을 전부 실측값으로 바꾼다.
2. 앞으로 strain 계열은 **셀 고정(ISIF=2)** 으로 돌리고, 결과 POSCAR 에서 변형률을
   되재서 명목값과 일치하는지 확인한 뒤에 쓴다.
3. **한 계열 안에서** 기준 무변형 셀을 하나로 통일한다 (parent 계열과 mirror 계열의
   기준이 섞이면 위 3절 같은 불일치가 생긴다).
4. 비등방(0.16 %p)은 양쪽 공통이므로 별도 이슈로 분리해 다룬다 — 급하지 않다.
