# parent 와 mirror 의 Weyl 위치가 계속 어긋나는 이유 — 격자가 아니라 FORCE_SETS 다

## 1. 두 무변형 구조는 사실상 같은 셀이다

축 길이(정렬, Å):

```
parent_pristine   4.996952  5.018972  5.203031
pristine_mirror   4.996880  5.018807  5.203003
차이 (%)            0.0014    0.0033    0.0005
```

**0.003 % 이내.** 구조적으로 구별이 안 된다.

## 2. 그런데 Weyl 위치는 0.030 어긋난다

축 규약이 다르므로(parent 는 편극축=k3, mirror 는 편극축=k2) **축 길이로 짝지어**
거울축 성분을 (긴 거울축, 짧은 거울축)으로 재표기하면:

| | 긴 거울축 (5.203) | 짧은 거울축 (4.997) |
|---|---|---|
| parent_pristine | **0.14649** | **0.07085** |
| pristine_mirror | **0.16103** | **0.09752** |
| 차이 | 0.0145 | 0.0267 |

크기 **0.0304 (환산)**. 짧은축 성분 기준으로는 **27 %** 차이다.

## 3. 격자로는 설명이 안 된다

기존 감도 추정은 **격자 0.09 % 차이 → Weyl 0.063 이동** (≈ 0.7 / 1 %)이었다.
여기 격자 차이는 0.003 % 이므로 예측 이동량은 **0.002** — 실제 관측 0.030 의
**1/15** 밖에 안 된다.

→ **격자가 원인이 아니다.**

## 4. 원인은 힘상수(=DFT 설정)다

parent 와 mirror 는 180° 도메인 짝이다. m_polar 가 k 를 Pca2₁+시간역전 궤도 안으로
보내므로 **같은 변형이면 모든 k 에서 주파수가 정확히 같아야 하고, chirality 만 뒤집힌다**
(`results/domain_route/SUMMARY.md` 보론 C).

그런데 레포가 이미 측정해 둔 값: 두 FORCE_SETS 의 **주파수 최대 불일치 0.14 THz,
평균 0.03 THz**. 우리가 쫓는 band17-18 gap 은 1e-8 ~ 1e-2 THz 규모다.
**오차가 신호보다 10 ~ 10⁷ 배 크다.**

0.14 THz 짜리 스펙트럼 오차가 Weyl 을 0.03 움직이는 것은 전혀 이상하지 않다.
즉 "거의 안 바뀌었는데 왜 다르냐"의 답은 — **구조는 안 바뀌었고, 계산이 바뀌었다.**

## 5. 확인 방법 (엄밀하고 값싸다)

parent 와 mirror 는 등거리 변환으로 연결되므로, **임의의 k 몇 점에서 두 데이터셋의
36 밴드 주파수를 대조**하면 된다. 축 대응만 맞추면 부호까지 포함해 일치해야 한다.
일치하지 않는 양이 그대로 **그 계산 설정의 오차 상한**이다.

이건 새 DFT 없이 지금 있는 FORCE_SETS 로 바로 할 수 있고, 이미 0.14 THz 로 측정돼 있다.

## 6. 함의

- **계열을 섞은 비교는 성립하지 않는다.** 지금 소멸 임계 −0.77 % ~ −1.00 % 도
  −0.77 % 는 mirror 계열, −1.00 % 는 parent 계열이라 이 오차를 정면으로 탄다.
- 따라서 **한 계열 안에서 두 점**을 잡아야 임계가 확정된다.
- 좌표값을 소수점 4~5 자리로 인용할 때는 어느 계열/어느 설정인지 반드시 명시할 것.
