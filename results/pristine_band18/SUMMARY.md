# parent_pristine — Γ–Z 경로 근처, band 18 위쪽에 무엇이 있는가

질문: "18번째 밴드 위에 Γ–Z 경로 근처에 있는 Weyl phonon".

**답: Weyl phonon 이 아니다. 거울면이 보호하는 nodal line 두 개가 Γ–Z 축에서
교차하는 지점이다.** chirality 는 대칭으로 0 이 강제된다.

(진행 중: 19–20 / 20–21 gap 의 Γ–Z 근처 박스, 그리고 Γ–Z 에서 먼 곳의
band 18–19 일반위치 후보 5개 검증. 끝나면 §4, §5 를 채운다.)

## 1. Γ–Z 선 위의 축퇴 자체

`weyl_scan.py` 의 `get_ph` (phonopy + Gonze NAC) 로 Γ–Z 를 201점 훑고
1D 최소화로 조인 결과:

| | 값 |
|---|---|
| 위치 | **(0, 0, 0.0500449)** |
| gap (18–19) | **1.64e−12 THz** |
| 주파수 | **10.029839 THz = 41.47 meV** |

선 위에서 gap 이 `k3` 에 선형으로 열린다 (`k3` 를 ±0.001 옮기면 1.6e−3 THz).
밴드 그림에서 보면 깔끔한 선형 교차로 보이는 게 이것이다.

## 2. 왜 Weyl 이 될 수 없는가 — 대칭이 먼저 답한다

parent_pristine 의 Pca2₁ 조작 (spglib, `--mode sym`):

| op | R 대각 | t | k 공간에서 |
|---|---|---|---|
| op0 | (1,1,1) | (0,0,0) | 항등 |
| op1 | (−1,−1,1) | (0,0,0.5) | 2₁ screw ∥ 편극축 a₃ |
| op2 | (−1,1,1) | (0.5,0,0.5) | glide 거울, 불변면 **k1 = 0, 0.5** |
| op3 | (1,−1,1) | (0.5,0,0) | glide 거울, 불변면 **k2 = 0, 0.5** |

Γ–Z 선은 `(0, 0, k3)` 이므로 **거울면 `k1=0` 과 `k2=0` 에 동시에** 들어 있다.
거울은 chirality 부호를 뒤집으므로 불변 자리에서는 χ = 0 이 강제된다.
즉 Γ–Z 선 위·근처의 이 축퇴는 구조적으로 Weyl 이 아니다.
대신 glide 고유값이 다른 두 밴드가 거울면 안에서 만나 **nodal line** 을 만든다.

## 3. 세 가지 실측 근거

### 3.1 구속 없는 3D refine 이 한 점이 아니라 여러 점에서 gap = 0 을 낸다

씨앗을 조금씩 옮겨 Nelder-Mead 를 돌리면:

| 씨앗 | 도달점 | gap |
|---|---|---|
| (0, 0, 0.050) | (0.0000000, 0.0000001, 0.0500449) | **0.000e+00** |
| (0.005, 0, 0.050) | (0.0049830, 0.0000000, 0.0501585) | **0.000e+00** |
| (0, 0.005, 0.050) | (0.0000000, 0.0050160, 0.0505362) | **0.000e+00** |
| (0.02, 0.02, 0.050) | (0.0000000, 0.0255532, 0.0616795) | 1.8e−15 |
| (0.05, 0.02, 0.050) | (0.0000000, 0.0129579, 0.0532527) | **0.000e+00** |
| (0.02, 0.05, 0.080) | (0.0000000, 0.0762700, 0.1166847) | **0.000e+00** |

고립 노드라면 전부 한 점으로 모인다. 도달점이 다 다르고 모두 `k1=0` 또는
`k2=0` 위다 — 축퇴가 점이 아니라 **선**이라는 직접 증거다.

### 3.2 두 선을 BZ 전체에 걸쳐 추적했다

각 `k1`(또는 `k2`)마다 `k3` 를 1D 최소화하며 따라갔다.

`k2 = 0` 평면 안의 선:

| k1 | 0.00 | 0.02 | 0.06 | 0.10 | 0.18 | 0.26 | 0.30 | 0.40 | 0.45 | 0.50 |
|---|---|---|---|---|---|---|---|---|---|---|
| k3 | 0.0500 | 0.0519 | 0.0665 | 0.0958 | 0.1782 | 0.2657 | 0.3005 | 0.3461 | 0.3610 | (열림) |
| gap | 5e−10 | 4e−10 | 6e−10 | 2e−09 | 2e−10 | 8e−09 | 4e−11 | 3e−09 | 2e−09 | 8.6e−02 |
| E(18) | 10.030 | 10.037 | 10.091 | 10.208 | 10.605 | 11.070 | 11.250 | 11.491 | 11.554 | — |

`k1 = 0` 평면 안의 선:

| k2 | 0.00 | 0.02 | 0.06 | 0.10 | 0.18 | 0.26 | 0.35 | 0.45 | 0.50 |
|---|---|---|---|---|---|---|---|---|---|
| k3 | 0.0500 | 0.0574 | 0.0978 | 0.1440 | 0.2240 | 0.2718 | 0.2956 | 0.3027 | 0.3031 |
| gap | 5e−10 | 2e−10 | 2e−09 | 4e−09 | 8e−11 | 9e−09 | 5e−09 | 3e−09 | 1e−08 |
| E(18) | 10.030 | 10.046 | 10.156 | 10.323 | 10.644 | 10.821 | 10.937 | 11.027 | 11.041 |

`k1=0` 쪽은 BZ 경계(`k2=0.5`)까지 닿고, `k2=0` 쪽은 `k1≈0.45` 를 지나
`k1=0.5` 전에 열린다. 두 선은 `(0,0,0.0500449)` 에서 만난다.

### 3.3 Γ–Z 근처를 전수 탐색해도 거울면 밖 후보가 0 개다

`scripts/box_scan.py` 로 `k1, k2 ∈ [0, 0.20]`, `k3 ∈ [0, 0.5]` 박스를
41×41×51 로 훑었다 (`scan_box_nearGZ_band18.log`).

```
band 18-19, 박스 k1,k2<=0.20  최소 gap = 7.0437e-05
gap<0.030 국소최소 33개 -> 전부 미세화
  거울면(k1 또는 k2 = 0/0.5)으로 배수/거울면 위 : 33개
  일반 위치에 남은 것                          : 0개
```

CLAUDE.md 의 경고대로 **gap 순위로 자르지 않고 33개를 전부 미세화**했고,
판정은 "도달점이 일반위치에 머무는가" 로만 했다. 하나도 남지 않는다.

## 4. Γ–Z 에서 먼 곳의 band 18–19 일반위치 후보 (검증 중)

전 BZ 쐐기 N=41 (`scan_wedge_band18_N41.log`) 에서 거울면 밖에 5개가 남았다.
Γ–Z 에서는 멀다 (`k1 ≈ 0.12–0.40`).

```
(0.3968129, 0.3428222, 0.3476382)
(0.1151299, 0.3320865, 0.0000000)
(0.3014149, 0.0216838, 0.0000000)
(0.3188959, 0.1276345, 0.3247894)
(0.3334458, 0.1735790, 0.3302764)
```

이것들이 **고립점인지** (구 위 최소 gap 이 반지름에 비례하는지 — nodal line 이
구를 뚫으면 비례하지 않는다) 와 chirality 를 재는 중이다. 위 §3 이 보여준 대로
이 밴드쌍에는 nodal line 이 흔하므로, **확정 전까지는 후보로만 둔다.**

```bash
python3 scripts/weyl_scan.py --dir source/parent_pristine --band 18 --mode sym
python3 scripts/box_scan.py  source/parent_pristine 18 0.20 41 51 0.03 0 1
python3 scripts/weyl_scan.py --dir source/parent_pristine --band 18 --mode wedge -N 41 --thresh 0.03
python3 scripts/sphere_chirality.py source/parent_pristine <k1> <k2> <k3> 18
```

(band 18–19 를 보려면 18).
