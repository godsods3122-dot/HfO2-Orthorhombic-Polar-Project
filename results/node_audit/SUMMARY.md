## 1. Born 전치 문제 — 위치에 관한 한 결론 났다 (`CLAUDE.md` §1.3)

phonopy 를 기준값으로 두면 바로 갈린다. 두 후보를 phonopy 로 직접 재면:

| 규약 | 기록된 위치 | **phonopy 에서의 gap** | 판정 |
|---|---|---|---|
| **비전치** | (0.06377, 0, 0.12942) | **4.7e-06 THz** | **노드** |
| 전치 | (0.08115, 0, 0.14476) | **5.99e-02 THz** | 노드 아님 (5자리 차이) |

그리고 `polar=0` 평면을 201×201 (간격 0.0025) 로 훑어 최저점을 격자 미세화하면
**(k1, k3) = (0.0637716, 0.1294181)**, gap 3.9e-07, E 10.365955 THz 로 수렴한다.
`CLAUDE.md` §2.2 의 비전치 기록과 소수점 5자리까지 일치한다.

**즉 Simphony 에 Born 을 넘길 때 비전치가 phonopy 와 맞는 규약이다.**
§1.3 의 원리적 논증(phonopy C 코드가 `np.dot(q, born[i])` 로 첫 인덱스를 축약)과도
같은 방향이다.

남는 것: §1.3 이 전치 쪽 근거로 들었던 "m1 에서 전치로 돌리면 chirality
−1,−1,+1,+1 이 재현된다" 는 여전히 설명되지 않았다. 다만 위치 검사는 정량적이고
5자리 차이로 갈리므로 그쪽이 결정적이다. 또한 이 검사는 **BORN 파일 자체가 올바른
규약으로 저장됐는지**(DFT 쪽 문제)는 말해주지 않는다 — 그건 별개다.

## 2. ⚠️ 탐색 방법의 결함 — gap 순위로 자르면 진짜 노드를 놓친다

**이게 이번 감사의 핵심이다.** 기약 쐐기 N=61 (226,981점) 에서 대칭 강제 자리를
마스킹하고 남은 일반위치 후보를 gap 순으로 세우면, m1 의 **실제 노드 두 개가**

| 노드 | 최근접 격자점 | 그 점의 gap | **순위** |
|---|---|---|---|
| polar=0 (0.06377, 0, 0.12942) | (0.0667, 0.0000, 0.1333) | 1.24e-02 | **907위** |
| 일반위치 (0.41895, 0.39521, 0.26258) | (0.4167, 0.3917, 0.2667) | 1.65e-02 | **1970위** |

1위 후보의 격자 gap 은 1.58e-03 이다. **진짜 노드보다 8~10배 얕아 보인다.**

상위 8개를 전부 미세화하면 결과는 이렇다:

```
(0.4917,0.3750,0.2583) -> (0.500000,0.376812,0.258404)  거울면 k1=0.5
(0.4917,0.1583,0.4917) -> (0.500000,0.147233,0.500000)  거울면
(0.4917,0.1667,0.4917) -> (0.500000,0.155566,0.500000)  거울면
(0.4917,0.1500,0.4917) -> (0.500000,0.138900,0.500000)  거울면
(0.3833,0.4917,0.2750) -> (0.394434,0.500000,0.263900)  polar=0.5 nodal plane
(0.4833,0.1583,0.4917) -> (0.487657,0.156944,0.500000)  거울면
(0.3750,0.4917,0.2750) -> (0.386100,0.500000,0.263900)  polar=0.5 nodal plane
(0.4917,0.1417,0.4917) -> (0.500000,0.130566,0.500000)  거울면
```

**8개 전부 대칭이 강제하는 자리(χ=0)로 배수된다. 진짜 노드는 하나도 없다.**

### 왜 이렇게 되나

콘이 심하게 기울어 있어서(type-II, m1 의 tilt 는 축에 따라 27 / 0.05 / 290) 노드
주변 골이 **얕고 넓다**. 반면 nodal plane 과 거울선은 평면/선 전체가 정확히 축퇴라
그 근처 격자점은 어디를 찍어도 gap 이 작게 나온다. 그래서 **대칭 강제 자리가 격자
gap 순위를 싹 쓸어간다.**

### 그래서 지켜야 할 것

1. **gap 순위로 후보를 자르지 말 것.** 상위 N개만 미세화하는 절차는 이 물질에서
   작동하지 않는다.
2. **미세화 도달점이 대칭면인지로 걸러낼 것.** 판정 기준은 gap 크기가 아니라
   "일반위치에 머무는가" + "χ 가 여러 반지름에서 정수로 안정한가".
3. **어떤 구조에 대해서도 "노드는 이것뿐"이라고 말할 수 없다.** 알려진 노드조차
   907위/1970위다. 완전성 주장은 근거가 없다.

알려진 m1 노드들이 원래 어떻게 발견됐는지 보면 납득이 된다 — polar=0 계열은
Simphony BulkGap 401² 로 **그 평면만** 조밀하게 훑어서 찾았지, 3D 쐐기 순위로
찾은 게 아니다.

# 부록 — Simphony 밖에서의 독립 검증 (2026-09)

"phonopy 로 확인했다"는 것만으로는 부족하다. phonopy 와 Simphony 는 **같은
FORCE_SETS·BORN** 을 쓰고, 위 검증은 **phonopy 의 동역학행렬 코드**를 그대로 썼다.
그래서 층을 나눠 각각 다른 경로로 다시 확인했다.

## A. 동역학행렬 자체 — hr.dat 에서 numpy 로 직접

`work/m1_mirror/hr_total.dat` (phonopy2TBDAT.py 가 쓴 질량가중 힘상수 × factor²,
Simphony 가 읽는 바로 그 파일) 에서 numpy 로

```
D(k) = Σ_R H(R)/deg · exp(2πi k·R),   sqrt(eig) = THz
```

를 직접 만들었다. phonopy 의 `DynamicalMatrix` 코드를 전혀 거치지 않는다.

**NAC 없는 phonopy 와 비교: k 14점 × 36밴드에서 최대 차이 3.33e-10 THz.**

→ `FORCE_SETS → 힘상수 → D(k)` 경로와 **Simphony 가 읽는 hr.dat 파일 자체**가
독립적으로 검증됐다. (`scripts/figs/chk_hr.py` 로 재현)

## B. Chirality — 서로 다른 알고리즘 3개

| 방법 | 원리 | polar=0 노드 | 일반위치 노드 | 비노드 대조군 |
|---|---|---|---|---|
| Fukui-Hatsugai-Suzuki Berry flux | 구면 플라케트 위상 합 | **+1** | **−1** | — |
| **Wilson loop / WCC 감김수** | 위도원 Wilson loop 의 det 위상을 극각으로 추적 | **−1** | **+1** | **0** |
| **속도행렬 행렬식 부호** | 2×2 유효 H 를 선형 전개, χ = sign det v | **+1** | **−1** | — |

WCC 는 전체 방향 규약이 반대라 부호가 뒤집힌다 — **상대 부호가 세 방법에서 전부
일치**한다. 반지름 0.002 / 0.004 / 0.008 / 0.010 1/Å 에서 전부 같은 정수.

**음성 대조군이 중요하다**: 노드가 없는 `(0.30, 0.20, 0.10)` 에서 WCC 감김수는
**정확히 0.0000** 이다. 이 방법이 아무 데서나 ±1 을 만들어내지 않는다.

(`scripts/figs/chk_wcc.py`, `scripts/figs/chk_local.py`)

## C. 진짜 선형 교차인가 (2차 접촉이 아닌가)

축퇴 2×2 부분공간에 사영해 `H = f₀·I + Σ_a f_a σ_a` 로 쓰고 `f_a = Σ_i v_ai δk_i`
의 3×3 속도행렬을 최소제곱으로 뽑았다 (14방향, R=1e-4).

| | polar=0 노드 | 일반위치 노드 |
|---|---|---|
| 선형 피팅 **R²** | **0.99999936** | **0.99999991** |
| v 의 특이값 | 0.1079 / 0.0673 / 0.0291 | 0.1747 / 0.0296 / 0.0121 |
| **조건수** | **3.71** | **14.4** |
| det v | +2.11e-04 | −6.24e-05 |
| \|tilt\| / 콘 최소축 | **7.00** | **25.8** |

조건수가 유한하고 det 가 0 이 아니다 → **선형 Weyl 이지 2차 접촉이 아니다.**
(`parent_m1` 의 `(0.1478, 0.0724, 0)` 은 2차 접촉 χ=0 이었다. 구분된다.)
tilt 비 7.0 / 25.8 → 둘 다 **type-II**.

부수적 대칭 점검: polar=0 노드의 tilt 는 편극축 성분이 **−2.2e-08 ≈ 0** 이다.
대칭이 강제하는 그대로다.

## E. ⚠️ 독립 검증이 **안 되는** 부분 — 여기가 진짜 위험

위 A~D 는 전부 **코드**를 검증한다. **입력은 검증하지 못한다.**

NAC 를 끄고 같은 자리를 재면:

| | NAC 끈 gap (기존 노드 자리) | 근처 최소 | 이동량 |
|---|---|---|---|
| polar=0 노드 | **6.75e-02 THz** | 3.39e-03 (안 닫힘) | 0.0685 rlu |
| 일반위치 노드 | **1.67e-01 THz** | 4.46e-02 (안 닫힘) | 0.0676 rlu |

**노드는 NAC 없이는 존재하지 않는다.** 즉 위치가 **Born 유효전하에 본질적으로
의존**한다 (극성 물질이니 당연하지만, 결과적으로 BORN 의 정확도가 곧 노드 위치의
정확도다).

따라서 남는 위험은 이렇게 정리된다.

| 층 | 검증 상태 |
|---|---|
| 동역학행렬 코드 | ✅ numpy 독립 구현과 3.3e-10 THz 일치 |
| NAC/LO-TO 코드 | ✅ 패치된 Simphony(Fortran) vs phonopy(C) 가 경로 239점 × 36밴드에서 3.4e-7 THz 일치 — **서로 다른 두 코드** |
| chirality 알고리즘 | ✅ 서로 다른 3개 방법 일치 + 음성 대조군 0 |
| 선형성·type 판정 | ✅ R² > 0.999999, 조건수 유한 |
| **FORCE_SETS** | ❌ **검증 안 됨** — 다른 DFT 계산이 필요 |
| **BORN** | ❌ **검증 안 됨** — 다른 DFT 계산이 필요. 그런데 노드 위치가 여기에 결정적으로 의존 |

### 그래서 남은 진짜 검증 방법 (계산 자원이 있을 때)

1. **다른 DFT 코드/설정으로 BORN 재계산** (DFPT ↔ Berry phase, 또는 다른 의사퍼텐셜).
   Z\* 가 몇 % 바뀔 때 노드가 얼마나 움직이는지가 곧 오차 막대다.
   지금 당장 할 수 있는 근사: BORN 을 ±2 % 스케일해 노드 이동량을 재는 것.
2. **FORCE_SETS 수렴 확인** — 지금은 2×2×2 초격자다. 3×3×3 이 있으면
   노드가 얼마나 움직이는지 본다.
3. **격자상수 수렴** — `results/weyl_trend/SUMMARY.md` 에 적힌 대로 노드 위치를
   ±0.01 로 묶으려면 격자를 0.019 % (0.0009 Å) 까지 수렴시켜야 한다.

**요약: 코드 쪽은 더 볼 게 없다. 노드 위치의 신뢰도는 이제 전적으로 DFT 입력의
품질 문제다.**
