# 예전 parent −1% 파일 검증 — 그리고 동료의 mirror m1 이 의미 있는가

`source/parent_m1_old/` (사용자 제공, 예전에 계산한 parent 계열 −1%).
가볍게: phonopy 쐐기 N=31 + 편극축=0 평면 조밀 스캔(161²).

## 0. 결론

1. **이 파일은 진짜 −1% 다.** (앞서 받은 `parent_m1` 이 −0.01% 였던 것과 다르다.)
2. **band 17-18 에 Weyl 이 없다.** 편극축=0 평면에도, 일반위치에도 없다.
3. **동료의 `m1_mirror` 는 라벨과 달리 −0.77% 다.** 그 변형에서는 Weyl 이 아직 살아
   있다. 즉 **소멸이 −0.77% 와 −1.00% 사이에서 일어난다.**

## 1. 격자 — 라벨 확인

축 길이 정렬값(Å)과 각 계열의 무변형 기준 대비 변형률:

| 구조 | 축 길이 | 변형률 (%) | 압축 두 축 평균 |
|---|---|---|---|
| parent_pristine (기준) | 4.996952 5.018972 5.203031 | — | — |
| **parent_m1_old** | 4.951351 5.055959 5.146887 | **−0.913 / +0.737 / −1.079** | **−1.00 %** |
| m1_mirror (동료 제공) | 4.954716 5.044581 5.167269 | −0.844 / +0.514 / −0.687 | **−0.77 %** |

압축 두 축 + 편극축 팽창 패턴은 둘 다 정상적인 biaxial 압축이다.
다만 **m1_mirror 는 −1% 라벨보다 23% 덜 눌려 있다.**

## 2. 대칭 — 축 규약 주의

```
parent_m1_old : 공간군 Pca2_1,  거울 = k1, k3   편극축 = k2
```

**이 예전 parent 파일은 `pristine_mirror`·`m1_mirror` 와 같은 축 규약**이고,
최근 받은 `parent_pristine`·`parent_m1` (거울 = k1,k2 / 편극축 = k3) 과는 **다르다.**
계열끼리 좌표를 비교할 때 반드시 확인할 것.

## 3. 탐색 결과 — Weyl 없음

**편극축=0 평면 (k2=0), 161×161, 간격 0.0031**

```
전체 최소 gap 3.04e-09 (거울선 위) | 경계에서 떨어진 최소 8.44e-03 | 거울면 밖 국소최소 0개
```

**기약 쐐기 N=31**

```
쐐기 최소 gap 1.77e-09 | 국소최소 32개 -> 거울면 30개, 일반위치 2개
   (0.1075802, 0.5000000, 0.4067941)   <- k2 = 0.5  = 편극축 nodal plane
   (0.5074903, 0.5000000, -0.0097944)  <- k2 = 0.5, 게다가 k1 ≈ 0.5 (거울선)
```

일반위치 후보 2개는 **둘 다 편극축 nodal plane(k2=0.5) 위**다. 그 평면은 2₁ screw +
시간역전이 축퇴를 강제하므로 χ=0 이고, 구면 위상수 자체가 정의되지 않는다.

→ **parent_m1_old 에는 band 17-18 Weyl 이 없다.**

## 4. 정면 비교 — 같은 스캔, 같은 설정

| 구조 | 압축 평균 | 편극축=0 평면 (161², 간격 0.0031) | 판정 |
|---|---|---|---|
| **m1_mirror** | −0.77 % | 후보 **(0.0656, 0, 0.1281)**, 경계 밖 최소 3.79e-03 | **Weyl 있음** |
| **parent_m1_old** | −1.00 % | 후보 **0개**, 경계 밖 최소 8.44e-03 | **Weyl 없음** |

동일한 밴드·동일한 격자·동일한 필터다. 차이는 정성적(있음/없음)이다.

## 5. 해석 — 동료의 mirror m1 은 의미가 있다, 단 "−1%" 로서는 아니다

- `m1_mirror` 는 **−0.77% 데이터점**이고, 그 변형에서 편극축=0 계열 Weyl 이 아직
  살아 있다는 유효한 정보를 준다.
- `parent_m1_old` 는 **−1.00% 데이터점**이고 거기서는 죽어 있다.
- 따라서 **소멸점이 −0.77% 와 −1.00% 사이**다. 이는 이전 세션의 ray 모델이 예측한
  **등방 biaxial 소멸 ε ≈ −0.98%** 를 정확히 괄호 안에 넣는다. 독립적인 방증이다.
- m2.5(−2.5%)·m3(−3%) 에 편극축=0 Weyl 이 없는 것도 같은 그림과 맞는다.

## 6. 주의 — 이 비교의 한계

- parent 와 mirror 는 180° 도메인 짝이므로 **같은 변형이면 모든 k 에서 주파수가
  정확히 같아야 한다.** 즉 계열을 섞은 비교는 두 데이터셋의 DFT 설정이 같을 때만
  성립한다. 레포는 parent/mirror FORCE_SETS 가 0.03~0.14 THz 어긋난다고 기록했다.
  여기서는 차이가 **정성적**이고 변형률도 실제로 다르므로 물리일 가능성이 높지만,
  **확정하려면 한 계열 안에서 −0.77% 와 −1.00% 두 점**이 필요하다.
- 쐐기가 N=31(간격 0.0167)이라 아주 날카로운 일반위치 노드는 놓칠 수 있다.
  "없음"은 편극축=0 평면에 대해서는 조밀 스캔으로 뒷받침되지만, 일반위치 전역에
  대해서는 N=31 수준의 진술이다.
- m2.5·m3 에는 **일반위치** Weyl 이 있는데 −1% 에는 없다. 계열이 다르므로 단순
  단조 추세로 읽지 말 것.

## 재현

```bash
python3 scripts/weyl_scan.py --dir source/parent_m1_old --band 17 --mode sym
python3 scripts/weyl_scan.py --dir source/parent_m1_old --band 17 --mode plane \
        --fixed-index 1 --fixed-value 0.0 -N 161
python3 scripts/weyl_scan.py --dir source/parent_m1_old --band 17 --mode wedge -N 31
```

## 7. 정정 — N=31 이 노드를 놓쳤다. parent_m1_old 에도 Weyl 이 있다

"쐐기가 N=31 이라 성기다"는 지적에 따라 **N=61**(간격 0.0083, 해상도 2배)로 다시
돌린 결과, **일반위치 노드가 하나 더 나왔다.** 5절의 "Weyl 없음"은 틀렸다.

### 새로 나온 노드 (정밀화 후)

```
k = (0.3608834, 0.4347050, 0.2306425)     gap = 0.00e+00
f = 11.94118 THz = 49.38 meV = 398.31 cm^-1
chi = +1   (반지름 0.002 / 0.004 에서 동일)
```

완전 일반위치다. 가장 가까운 대칭면까지 거리: k1 → 0.139, 편극축 k2 → 0.065,
k3 → 0.231. 어느 거울면에도, 편극축 nodal plane 에도 걸려 있지 않다.

거울지표가 k1, k3 이므로 궤도는 (±k1, ±k2, ±k3) 8점, 거울에서 χ 가 뒤집혀
+4 / −4, 알짜 0. **BZ 전체에 8개.**

### N=31 vs N=61 비교

| 구조 | N=31 일반위치 | N=61 일반위치 | 변화 |
|---|---|---|---|
| **parent_m1_old** | (편극 nodal plane 위 2개뿐) | **+ (0.36088, 0.43471, 0.23064)** | **새 노드 1개** |
| m2.5_mirror | (0.20768, 0.29555, 0.43458) | 동일 (중복만 증가) | 없음 |
| m3_mirror | 2개 | 동일 (중복만 증가) | 없음 |

m2.5·m3 는 N=61 에서도 그대로다. **놓친 것은 parent_m1_old 뿐이었다.**

### 5절 중 유지되는 것 / 철회되는 것

- **철회**: "parent_m1_old 에는 band 17-18 Weyl 이 없다."
  → **있다.** 일반위치에 χ=+1 짜리가 있다.
- **유지**: "**편극축=0 평면**에는 없다." 이건 쐐기가 아니라 161×161 조밀 평면
  스캔(간격 0.0031)으로 확인한 것이라 해상도 문제를 타지 않는다.
- **유지**: 편극축=0 계열의 소멸이 −0.77% 와 −1.00% 사이라는 결론. 근거가 양쪽 다
  조밀 평면 스캔이기 때문이다.
- **유지**: 동료의 m1_mirror 는 −0.77% 데이터점으로서 의미가 있다.

### 정리 — 두 계열을 분리해서 봐야 한다

| 구조 | 압축 평균 | 편극축=0 계열 | 일반위치 계열 |
|---|---|---|---|
| parent_pristine | 0 % | **있음** (3중 구조, 알짜 ±1) | (미조사) |
| m1_mirror | −0.77 % | **있음** | (미조사) |
| **parent_m1_old** | −1.00 % | **없음** | **있음** (χ=+1, 49.38 meV) |
| m2.5_mirror | −2.5 % | 없음 | 있음 (χ=+1, 49.13 meV) |
| m3_mirror | −3.0 % | 없음 | 있음 ×2 (χ=+1 49.57 meV, χ=−1 48.20 meV) |

편극축=0 계열은 압축과 함께 사라지고, **일반위치 계열은 −1% 이후 계속 존재한다.**
에너지도 48~50 meV 로 모여 있어 같은 계열로 보인다.

### 남는 한계 (정직하게)

- **N=61 도 수렴을 증명하지 못한다.** N=31→61 에서 실제로 노드가 하나 늘었다.
  N=61 에서 더 안 늘었다는 것이 "없다"의 증명은 아니다. 확정하려면 N=81 이상이나
  후보 영역의 국소 고해상도 스캔이 필요하다.
- 위 표의 "미조사" 칸(parent_pristine·m1_mirror 의 일반위치 계열)은 아직 안 봤다.
  두 계열이 공존하는지 확인하려면 그 둘도 N=61 로 돌려야 한다.
