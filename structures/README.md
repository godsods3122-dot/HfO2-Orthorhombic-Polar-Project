# 생성 구조 안내 (`scripts/make_structures.py`)

모두 `source/pristine_mirror/POSCAR` 에서 파생. 축 규약: **a=4.9969, b=5.0188(편극축),
c=5.2030 Å**, 거울지표 = k1(a), k3(c), 편극축 = k2(b).

180° 짝을 만드는 거울: 편극축 좌표에 대해 원점 s = 0.3815 로 반전.
최대 원자변위 0.704 Å, 극성 모드 RMS 0.346 Å.

---

## 1. `polar_amplitude/` — 극성 진폭 손잡이 (12원자, 셀 고정)

`r0 + λ·u` 로 만든다. `r0` = 비극성 모체, `u` = 극성 모드,
**λ = 1 − 2x** (x = 무작위로 섞인 mirror 도메인 분율).

| 파일 | λ | x | 공간군 | 반전 | 최소원자거리 |
|---|---|---|---|---|---|
| `POSCAR_lambda1.00` | 1.00 | 0.00 | Pca2₁ | 없음 | 2.025 Å | ← pristine 과 동일 (대조군) |
| `POSCAR_lambda0.80` | 0.80 | 0.10 | Pca2₁ | 없음 | 1.983 Å |
| `POSCAR_lambda0.60` | 0.60 | 0.20 | Pca2₁ | 없음 | 1.949 Å |
| `POSCAR_lambda0.40` | 0.40 | 0.30 | Pca2₁ | 없음 | 1.925 Å |
| `POSCAR_lambda0.00` | 0.00 | 0.50 | **Pbcm** | **있음** | 1.905 Å | ← 비극성 모체 (대조군) |

**생김새**: 원래 결정과 **격자도 원자 배열 위상도 완전히 같고**, Hf/O 가 편극축(b)
방향으로 밀려 있는 양만 λ 배로 줄어든 것. 겉보기로는 구분이 안 되고 자발 분극만
λ 에 비례해 작아진다. λ=0 이면 Hf/O 가 b 방향 대칭 위치로 돌아가 반전대칭이 생긴다.

**용도**: strain 과 독립인 제3의 Pca2₁-보존 손잡이. 각 λ 에서 FORCE_SETS+BORN 을
받으면 Weyl 이 λ 를 따라 어디로 가고 **어디서 죽는지**가 나온다.
λ=0 은 반전대칭이라 Weyl 이 반드시 0 개여야 한다 — 계산 파이프라인 자체의 검산이 된다.
셀을 고정했으므로 이완할 때 **ISIF 로 셀을 풀면 안 된다** (풀면 λ=1 로 되돌아간다).
극성 모드 진폭을 고정한 constrained relaxation 이거나, 아예 이완 없이 그대로 쓸 것.

## 2. `wall_registry/` — 180° 도메인 벽의 두 레지스트리

c 법선 180° 벽. 편극은 ±b 로 **벽면 안에 누워 있어** 결합전하가 없다(중성 벽).

| 파일 | nA:nB | 원자수 | 주기 | 공간군 | 최소원자거리 |
|---|---|---|---|---|---|
| `POSCAR_tau0.00_2to1` | 2:1 | 36 | 15.61 Å | P2₁ | **1.905 Å** |
| `POSCAR_tau0.50_2to1` | 2:1 | 36 | 15.61 Å | P2₁ | **1.302 Å** |
| `POSCAR_tau0.00_4to2` | 4:2 | 72 | 31.22 Å | P2₁ | 1.905 Å |
| `POSCAR_tau0.50_4to2` | 4:2 | 72 | 31.22 Å | P2₁ | 1.302 Å |

**생김새**: c 축을 따라 원래 방향 도메인 A 를 nA 층, 편극이 뒤집힌 도메인 B 를 nB 층
쌓은 것. 층은 원시셀 단위(c = 5.203 Å)이고, 2:1 이면 A 가 10.41 Å, B 가 5.20 Å.
셀 안에 벽이 **두 장**(A→B, B→A) 들어간다. 알짜 분극은 (nA−nB)/(nA+nB) = **1/3**.
`tau` 는 B 블록을 c 방향으로 민 양(원시셀 단위)이고, **tau=0 과 tau=0.5 가 glide 가
서로 짝지어 주는 두 레지스트리**다.

**핵심**: 두 레지스트리는 좌표계 무관 지문으로 봐도 **다른 구조**다
(Hf–Hf 거리 최대 1.11 Å 차이, 4 Å 이내 이웃 개수도 다름). 그래서 형성에너지가
축퇴일 이유가 없고, **총에너지 차이가 이 갈래 전체를 판정한다** — 유의미하게 다르면
자연이 한 레지스트리를 고르고, 그러면 주기성이 전혀 없어도 배위평균에서 glide 가
깨진다 (`results/domain_route/SUMMARY.md` 보론 H).

**주의**:
- **미이완 이상화 벽**이다. 특히 tau=0.50 은 최소원자거리 1.302 Å 로 Hf–O 정상값
  (~2.0 Å)보다 훨씬 짧아 크게 이완·재구성될 것이다. 이완 후에도 두 레지스트리가
  구분되는지, 그리고 에너지 차이가 얼마인지가 실제 답이다.
- 비교는 **같은 셀 크기·같은 계산 조건**으로 tau=0 과 tau=0.5 를 나란히 돌릴 것.
  2:1 은 벽 사이가 5–10 Å 뿐이라 벽끼리 상호작용한다. 4:2 로 한 번 더 확인해
  수렴을 봐야 한다.
- 셀 벡터는 이완해도 되지만 **c 축 길이를 풀면 벽 간격이 바뀌므로** 두 tau 에서
  같은 조건을 쓸 것.
- 주기 셀 안의 두 벽(A→B, B→A)이 이 구성에서는 레지스트리가 **함께** 움직인다.
  각 벽이 독립적으로 고르는 경우까지 보려면 더 큰 셀에서 tau₁≠tau₂ 구성이 필요하다.
